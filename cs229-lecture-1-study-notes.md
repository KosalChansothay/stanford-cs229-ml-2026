## 2. Key Concepts & Definitions

### General Machine Learning Definitions
*   **Arthur Samuel's Definition (1959)**: The field of study that gives computers the ability to learn without being explicitly programmed [9, 10].
*   **Tom Mitchell's Definition (1998)**: A computer program is said to learn from experience $E$ with respect to some class of tasks $T$ and performance measure $P$, if its performance at tasks $T$, as measured by $P$, improves with experience $E$ [10, 11].
    *   **Experience ($E$)**: The data used for learning, which includes web text, real-world measurements, human-labeled pairs, or synthetic data (such as "thinking tokens" generated by models) [11, 12].
    *   **Task ($T$)**: The goal or problem domain. Historically highly specific (e.g., classifying an image) [12], but modernly generalized (e.g., a single LLM solving millions of distinct tasks) [12].
    *   **Performance Measure ($P$)**: The metric used to evaluate and drive learning (e.g., classification accuracy, model perplexity, or game win rate) [12, 13].

### Machine Learning Paradigms
*   **Supervised Learning**: Learning where every training example consists of an input $x$ and an associated output/label $y$ [18, 21]. The model's objective is to learn a mapping $f(x) \approx y$ [18, 19].
    *   **Regression**: A supervised learning task where the output $y$ is a continuous numerical variable (e.g., predicting housing prices) [22].
    *   **Classification**: A supervised learning task where the output $y$ is a discrete categorical variable or label (e.g., classifying townhouse vs. single-family house, or predicting the next token in an LLM from a large vocabulary) [22, 23, 24].
*   **Unsupervised Learning**: Learning from a dataset containing only inputs $x$ without any ground-truth labels or outputs $y$ [34, 35]. The goal is to discover "interesting structure" in the data [35, 36].
    *   **Clustering**: The process of grouping data points together based on similarity so that points in the same group are more similar than those in other groups [36, 37].
    *   **Representation Learning / Embeddings**: Mapping raw, high-dimensional inputs (e.g., words, images) into lower-dimensional continuous vectors that capture semantic relationships [41, 42].
*   **Reinforcement Learning (RL)**: A paradigm where an agent learns to make sequential decisions through trial-and-error interaction with an environment [49, 50, 56].
    *   **Sequential Decision-Making**: Actions taken by the agent at the current step affect future states and future feedback, meaning decisions cannot be evaluated in isolation [51, 54].
    *   **Stochastic Sampling**: Generation of discrete tokens/actions by sampling from a probability distribution. This step is non-differentiable, meaning standard gradient backpropagation cannot flow directly through the sampling process, which makes RL necessary [53, 54, 60].

## 3. Step-by-Step Workflows & Explanations

### A. The Supervised Learning Workflow
To fit a model using supervised learning, the following pipeline is executed:

1.  **Formulate Inputs ($x$) and Outputs ($y$)**: Define what features describe the input and what target needs to be predicted [18, 21].
2.  **Collect Training Examples**: Construct a dataset of pairs:
    $$\mathcal{D} = \{ (x^{(1)}, y^{(1)}), (x^{(2)}, y^{(2)}), \dots, (x^{(N)}, y^{(N)}) \}$$
3.  **Define Model Architecture**: Select a hypothesis family $h_\theta(x)$ parameterized by parameters $\theta$ (e.g., linear regression, quadratic curve, or neural network) [19, 32].
4.  **Define a Loss Function**: Establish a mathematical function $\mathcal{L}(\theta)$ that penalizes deviations between the predicted output $h_\theta(x)$ and the true label $y$ [20, 33].
5.  **Optimize (Compute Gradients)**: Compute the gradient of the loss function with respect to the parameters $\theta$ and update the parameters using optimizers (e.g., Gradient Descent) [20, 33]:
    $$\theta \leftarrow \theta - \alpha \nabla_\theta \mathcal{L}(\theta)$$
    *For deep neural networks, this is implemented using **backpropagation** to automatically compute gradients across millions/billions of parameters [32, 33, 34].*
6.  **Evaluate**: Test the trained model $h_{\theta^*}(x)$ on unseen inputs to ensure generalizability.

### B. The Unsupervised Clustering Workflow
Unsupervised clustering groups data points without pre-existing labels:

1.  **Collect Unlabeled Data**: Construct a dataset $\mathcal{D} = \{ x^{(1)}, x^{(2)}, \dots, x^{(N)} \}$ [35].
2.  **Define Distance Metric**: Establish how similarity is measured (e.g., Euclidean distance or Cosine similarity) [36, 37].
3.  **Apply Clustering Algorithm**: Partition the $N$ points into $K$ distinct clusters [37] (detailed in Lectures 9 & 10).
4.  **Analyze Structure**: Reorder, visualize, or sort the clusters to uncover latent biological, document, or behavioral groupings [38, 40].

### C. The Reinforcement Learning (Trial-and-Error) Loop
Unlike supervised learning where data is static, RL involves active, iterative collection and policy optimization [55, 56]:

1.  **Initialize Policy**: Set up a policy $\pi_\theta(a|s)$ that maps current state $s$ to a probability distribution over actions $a$ [53].
2.  **Interact & Collect Trajectories**: Run the policy in the environment to generate sequence data (trajectories $\tau$) [57]:
    $$\tau = (s_1, a_1, r_1, s_2, a_2, r_2, \dots)$$
3.  **Verify & Reward**: Use a reward model or an automated verifier to evaluate the sequence of actions and return a scalar reward $r_t$ [59, 60].
4.  **Update via Policy Gradient**: Since the sampling of actions is a stochastic, non-differentiable step, use RL algorithms (e.g., Policy Gradient) to update $\theta$, increasing the likelihood of actions that yielded higher rewards [53, 54, 60, 61].
5.  **Bootstrap**: Use the updated, stronger policy to generate better trial data, and repeat the loop [58, 59].

### 3. Image Classification & Bounding Box Detection [26, 29]
*   **Image Classification**: Raw pixel inputs ($x$) map to a discrete categorical object class ($y$, e.g., flamingo, Egyptian cat) [26, 29].
    *   *ImageNet Case Study*: Fei-Fei Li's team collected 1 million image-label pairs (20x larger than the next largest dataset at the time) [26, 27]. AlexNet (Hinton, Krizhevsky, Sutskever) was trained on this, triggering the modern deep learning era [27, 28].
*   **Bounding Box Localization**: Outputting continuous boundaries [29].

    *   **Output ($y$)**: Four continuous numbers $(x_1, y_1)$ representing the bottom-left corner, and $(x_2, y_2)$ representing the top-right corner to uniquely localize the object [30].

### 6. Reinforcement Learning for Robots and LLMs [50, 59]
*   **Robotics Walking**: A quadruped robot's policy outputs joint motor controls at each timestep [50, 51]. At Iteration 10, it cannot walk, but through trial-and-error, it optimizes its walking trajectory over many iterations [50, 56, 57].
*   **Large Language Model Alignment (RLHF / RLVR)**:
    *   An LLM generates long chains of thought or text via stochastic token sampling [52, 53, 61].
    *   Since token generation involves sampling from a vocabulary (e.g., 50k to 250k options) [25] and is non-differentiable [53], standard backpropagation cannot be used end-to-end [53, 60].
    *   Instead, a reward model or automated verifier evaluates the output to provide a scalar reward [59, 60], and **policy gradients** are used to adjust token probabilities [60, 61].
