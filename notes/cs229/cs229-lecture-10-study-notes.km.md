# Stanford CS229: ការរៀនរបស់ម៉ាស៊ីន (Spring 2026)
## មេរៀនទី ១០: ម៉ូដែលល្បាយហ្គោស (EM) និងការវិភាគសមាសភាគចម្បង (PCA)

### ១. សេចក្តីសង្ខេប (Summary)
មេរៀននេះបង្រួបបង្រួមការយល់ដឹងអំពី **ការរៀនគ្មានការត្រួតពិនិត្យ (Unsupervised Learning)** ដោយស្វែងយល់ពីបទដ្ឋានគ្រឹះពីរគឺ៖ ការកសាងម៉ូដែលអថេរលាក់កំបាំងតាមប្រូបាប៊ីលីតេ (Probabilistic Latent Variable Modeling) និងការកាត់បន្ថយវិមាត្រលីនេអ៊ែរដែលមិនផ្អែកលើប្រូបាប៊ីលីតេ (Non-probabilistic Linear Dimensionality Reduction)។ 

ដោយផ្លាស់ប្តូរពីការប្រមូលចង្កោមបែបស្រទន់ដំបូងក្នុង GMMs សាស្ត្រាចារ្យបានទាញរកជាផ្លូវការនូវ **ក្បួនដោះស្រាយរំពឹងទុក-អតិបរមា (Expectation-Maximization Algorithm - EM)**។ តាមរយៈការណែនាំនូវ **ព្រំដែនក្រោមនៃភស្តុតាង (Evidence Lower Bound - ELBO)** ដោយប្រើបច្ចេកទេសបំណែងចែក $Q$ (Q-distribution trick) និងការប្រើប្រាស់ **វិសមភាពហ្សង់សែន (Jensen's Inequality)** លើរចនាសម្ព័ន្ធផត ក្បួនដោះស្រាយ EM ត្រូវបានបង្ហាញថាជាវិធីសាស្ត្រឡើងតាមកូអរដោនេ (Coordinate Ascent) ដ៏តឹងរ៉ឹងខាងគណិតវិទ្យា ដែលធានានូវការរួមចំណុះម៉ូណូតូនទៅកាន់ចំណុចអតិបរមាក្នុងតំបន់នៃលោការីតលទ្ធភាពរឹម (Marginal Log-Likelihood)។ 

បន្ទាប់មក មេរៀនបានប្តូរទៅកាន់ **ការវិភាគសមាសភាគចម្បង (Principal Component Analysis - PCA)** ដែលជាក្បួនដោះស្រាយស្នូលដ៏មានឥទ្ធិពលបំផុត។ ការទាញរកតាមបែបគណិតវិទ្យាបានស្រាយបញ្ជាក់ថា ការធ្វើអតិបរមាកម្មលើវ៉ារ្យ៉ង់ទិន្នន័យបញ្ចាំង (Projected Variance) គឺសមមូលទាំងស្រុងទៅនឹងការកាត់បន្ថយកំហុសសំណល់កសាងឡើងវិញកែង។ បញ្ហាបង្កើនប្រសិទ្ធភាពនេះត្រូវបានដោះស្រាយតាមបែបវិភាគដោយប្រើ **ការបំបែកតម្លៃផ្ទាល់ (Eigenvalue Decomposition)** នៃម៉ាទ្រីសកូវ៉ារ្យ៉ង់ជាក់ស្តែង ដោយបង្ហាញពីការពិតជាក់ស្តែងនៃប្រព័ន្ធទិន្នន័យ ដូចជា ការតម្រឹមកណ្តាលមធ្យម (Mean Centering), ការធ្វើមាត្រដ្ឋានលក្ខណៈទិន្នន័យ (Feature Scaling), និងបញ្ហាអស្ថិរភាពនៅពេលតម្លៃផ្ទាល់នៅជិតគ្នា (Spectrum-separation Instabilities)។

### ២. គោលគំនិតសំខាន់ៗ & និយមន័យ (Key Concepts & Definitions)
- **អថេរលាក់កំបាំង ($z$ - Latent/Hidden Variables)**: អថេរដែលមិនត្រូវបានសង្កេតឃើញដោយផ្ទាល់ ដែលតំណាងឱ្យរចនាសម្ព័ន្ធលាក់កំបាំងនៃទិន្នន័យ (ឧទាហរណ៍៖ ចង្កោមប្រភពដើមពិត ឬប្រភពពន្លឺនៃហ្វូតុង)។
- **ព្រំដែនក្រោមនៃភស្តុតាង (Evidence Lower Bound - ELBO)**: អនុគមន៍ព្រំដែនក្រោមជំនួស តាងដោយ $\mathcal{L}(Q, \theta)$ ដែលត្រូវបានកសាងឡើងតាមរយៈវិសមភាពហ្សង់សែន ដើម្បីប៉ាន់ស្មានពីក្រោមនូវលោការីតលទ្ធភាពរឹម $l(\theta)$។
- **ភាពម៉ូណូតូនតឹងរ៉ឹង (Strict Monotonicity)**: លក្ខណៈសម្បត្តិរួមចំណុះនៃក្បួនដោះស្រាយ EM ដែលធានាថាលោការីតលទ្ធភាពរឹម $l(\theta^{(t)})$ តែងតែកើនឡើង ឬនៅថេរនៅគ្រប់ជំហានធ្វើសារឡើងវិញ ដែលទប់ស្កាត់មិនឱ្យកើតមានការវិលជុំវិញ (Cycle Oscillations) ក្នុងតំបន់។
- **មេគុណឡាក្រង់ (Lagrange Multipliers)**: ឧបករណ៍បង្កើនប្រសិទ្ធភាពគណិតវិទ្យាដែលប្រើក្នុងជំហាន M-step ដើម្បីអនុវត្តលក្ខខណ្ឌកំហិតលើប៉ារ៉ាម៉ែត្រ ដូចជាការធានាថាវ៉ិចទ័រទម្ងន់ល្បាយមុន $\phi$ ស្ថិតនៅលើ Simplex នៃប្រូបាប៊ីលីតេ ($\sum_{j=1}^k \phi_j = 1$)។
- **សមាសភាគចម្បង (Principal Component)**: ទិសដៅវ៉ិចទ័រឯកតាអរតូណរម៉ាល់ $u$ ដែលក្តោបក្តាប់វ៉ារ្យ៉ង់អតិបរមានៃសំណុំទិន្នន័យដែលបានបញ្ចាំង។
- **ការតម្រឹមកណ្តាលមធ្យម (Mean Centering)**: ជំហានរៀបចំទិន្នន័យបឋមដោយរំកិលទិន្នន័យឱ្យមានមធ្យមជាក់ស្តែងស្មើនឹងសូន្យ ($\mu = 0$) ដែលធានាថាវ៉ិចទ័រផ្ទាល់របស់ PCA តំណាងឱ្យទិសដៅនៃវ៉ារ្យ៉ង់ ពុំមែនជាទិសដៅចង្អុលទៅកាន់ចំណុចកណ្តាលទិន្នន័យនោះឡើយ។
- **ការធ្វើមាត្រដ្ឋានឡើងវិញ (z-score Standardization)**: ការធ្វើឱ្យមានលក្ខណៈស្តង់ដារដោយចែកលក្ខណៈទិន្នន័យនីមួយៗនឹងគម្លាតស្តង់ដារជាក់ស្តែងរបស់វា ដែលការពារកុំឱ្យលក្ខណៈទិន្នន័យដែលមានតម្លៃលេខធំគ្របដណ្តប់លើការគណនាវ៉ារ្យ៉ង់របស់ PCA ដោយអយុត្តិធម៌។
- **លក្ខខណ្ឌវិសាលគមដាច់ពីគ្នា (Separated Spectrum Requirement)**: លក្ខខណ្ឌដែលតម្លៃផ្ទាល់នៃម៉ាទ្រីសកូវ៉ារ្យ៉ង់ជាក់ស្តែងត្រូវតែដាច់ចេញពីគ្នាយ៉ាងច្បាស់ ($\lambda_j \gg \lambda_{j+1}$) ដើម្បីឱ្យទិសដៅចម្បងដែលត្រូវគ្នាមានស្ថិរភាព និងអាចកំណត់អត្តសញ្ញាណបានច្បាស់លាស់នៅពេលទិន្នន័យមានការប្រែប្រួលតិចតួច។

### ៣. រូបមន្តគណិតវិទ្យា & ការទាញរក (Mathematical Formulations & Derivations)

#### ក. ការកសាង ELBO (បច្ចេកទេសបំណែងចែក Q - The Q-Distribution Trick)
យើងមានសំណុំទិន្នន័យ $\mathcal{D} = \{x^{(1)}, \dots, x^{(n)}\}$ និងម៉ូដែលអថេរលាក់កំបាំង $p(x, z; \theta)$។ លោការីតលទ្ធភាពរឹមមានការលំបាកខ្លាំងក្នុងការបង្កើនប្រសិទ្ធភាពដោយផ្ទាល់ ដោយសារតែផលបូកលើលំហអថេរលាក់កំបាំងស្ថិតនៅខាងក្នុងអនុគមន៍លោការីត៖
$$l(\theta) = \sum_{i=1}^n \log p(x^{(i)}; \theta) = \sum_{i=1}^n \log \sum_{z^{(i)}} p(x^{(i)}, z^{(i)}; \theta)$$

ដើម្បីបង្កើតអនុគមន៍ជំនួសក្នុងតំបន់ យើងពិនិត្យមើលចំណុចទិន្នន័យទោលមួយ (លុបសន្ទស្សន៍ $i$ ដើម្បីសម្រួលដល់ការសរសេរ)។ តាង $Q(z)$ ជាបំណែងចែកប្រូបាប៊ីលីតេចៃដន្យណាមួយលើលំហអថេរលាក់កំបាំង ដែល $Q(z) \ge 0$ និង $\sum_{z} Q(z) = 1$៖
$$\log p(x; \theta) = \log \sum_z p(x, z; \theta) = \log \sum_z Q(z) \frac{p(x, z; \theta)}{Q(z)}$$

យើងអាចបកស្រាយផលបូកនេះជាតម្លៃរំពឹងទុកគណិតវិទ្យាក្រោមបំណែងចែក $Q(z)$៖
$$\log p(x; \theta) = \log \mathbb{E}_{z \sim Q} \left[ \frac{p(x, z; \theta)}{Q(z)} \right]$$

ដោយសារអនុគមន៍លោការីតធម្មជាតិ $\log(t)$ គឺជាអនុគមន៍ផតដាច់ខាត យើងអនុវត្ត **វិសមភាពហ្សង់សែន (Jensen's Inequality)** ($\log \mathbb{E}[X] \ge \mathbb{E}[\log X]$) ដើម្បីទាញលោការីតចូលទៅក្នុងតម្លៃរំពឹងទុក៖
$$\log p(x; \theta) \ge \mathbb{E}_{z \sim Q} \left[ \log \frac{p(x, z; \theta)}{Q(z)} \right]$$
$$\log p(x; \theta) \ge \sum_z Q(z) \log \frac{p(x, z; \theta)}{Q(z)} = \mathcal{L}(Q, \theta)$$

ធ្វើផលបូកលើគ្រប់ចំណុចទិន្នន័យទាំង $n$ យើងទទួលបាន **ព្រំដែនក្រោមនៃភស្តុតាងសកល (Global Evidence Lower Bound - ELBO)**៖
$$l(\theta) \ge \sum_{i=1}^n \sum_{z^{(i)}} Q_i(z^{(i)}) \log \frac{p(x^{(i)}, z^{(i)}; \theta)}{Q_i(z^{(i)})}$$

#### ខ. ការស្រាយបញ្ជាក់ភាពប៉ះស្មើគ្នានៃ ELBO (ដំណោះស្រាយនៃ E-Step)
ដើម្បីធ្វើឱ្យព្រំដែនក្រោម $\mathcal{L}(Q, \theta)$ ប៉ះស្មើគ្នាល្អឥតខ្ចោះ (Tight) ទៅនឹងតម្លៃពិតនៅត្រង់ការប៉ាន់ស្មានបច្ចុប្បន្ន $\theta^{(t)}$ យើងត្រូវបំពេញលក្ខខណ្ឌដែលវិសមភាពហ្សង់សែនក្លាយជាសមភាព។ នេះកើតឡើងនៅពេលដែលអថេរចៃដន្យនៅខាងក្នុងតម្លៃរំពឹងទុកគឺជាចំនួនថេរធៀបនឹង $z$៖
$$\frac{p(x, z; \theta^{(t)})}{Q(z)} = c \implies p(x, z; \theta^{(t)}) = c \cdot Q(z)$$

ដោយសារ $Q(z)$ ជាបំណែងចែកប្រូបាប៊ីលីតេដែលមានផលបូកស្មើ ១ យើងធ្វើផលបូកលើអង្គសងខាងធៀបនឹង $z$ ដើម្បីស្វែងរកតម្លៃថេរ $c$៖
$$\sum_z p(x, z; \theta^{(t)}) = c \sum_z Q(z) \implies p(x; \theta^{(t)}) = c$$

ជំនួសតម្លៃ $c$ ចូលក្នុងសមីការសមាមាត្រខាងលើវិញ យើងទទួលបាន៖
$$Q(z) = \frac{p(x, z; \theta^{(t)})}{p(x; \theta^{(t)})} = p(z \mid x; \theta^{(t)})$$

ដូច្នេះ ព្រំដែនក្រោមគឺប៉ះស្មើគ្នាល្អឥតខ្ចោះ (ប៉ះខ្សែកោងលទ្ធភាពពិត) នៅពេល $Q(z)$ ត្រូវបានកំណត់ឱ្យស្មើនឹង **ប្រូបាប៊ីលីតេក្រោយ** នៃអថេរលាក់កំបាំង $z$ ដោយដឹងទិន្នន័យ $x$ និងប៉ារ៉ាម៉ែត្របច្ចុប្បន្ន $\theta^{(t)}$។

<p><em>រូបភាព៖ ធរណីមាត្រនៃជំហាន EM — ខ្សែកោងពណ៌បៃតងតំណាងឱ្យលោការីតលទ្ធភាពរឹមពហុកំពូល $l(\theta)$។ ខ្សែកោងពណ៌ទឹកក្រូចតំណាងឱ្យព្រំដែនក្រោមប៉ះ $\mathcal{L}(Q_t, \theta)$ ដែលប៉ះ $l(\theta)$ នៅត្រង់ $\theta^{(t)}$។ ការធ្វើអតិបរមាកម្មលើខ្សែកោងពណ៌ទឹកក្រូចផ្តល់នូវ $\theta^{(t+1)}$ ដែលធានាការកើនឡើងម៉ូណូតូន។</em></p>

#### គ. ការទាញរក PCA៖ ការធ្វើអតិបរមាកម្មលើវ៉ារ្យ៉ង់បញ្ចាំង (PCA Derivation)
តាង $\mathcal{D} = \{x^{(1)}, \dots, x^{(n)}\}$ ជាសំណុំទិន្នន័យដែលបានតម្រឹមកណ្តាលមធ្យមរួចរាល់ ($\sum_i x^{(i)} = 0$) ដោយ $x^{(i)} \in \mathbb{R}^d$។ យើងចង់ស្វែងរកវ៉ិចទ័រទិសដៅឯកតា $u \in \mathbb{R}^d$ ($u^T u = 1$) ដែលធ្វើឱ្យកូអរដោនេបញ្ចាំងនៃចំណុចទិន្នន័យតាមបណ្តោយ $u$ មានវ៉ារ្យ៉ង់ជាក់ស្តែងអតិបរមា។

ប្រវែងបញ្ចាំងនៃចំណុចទិន្នន័យ $x^{(i)}$ លើវ៉ិចទ័រឯកតា $u$ គឺកំណត់ដោយផលគុណស្កាលែ៖
$$\text{proj}(x^{(i)}) = x^{(i)T} u$$

ដោយសារទិន្នន័យត្រូវបានតម្រឹមកណ្តាលមធ្យម មធ្យមនៃកូអរដោនេបញ្ចាំងក៏ស្មើនឹង $0$ ដែរ។ វ៉ារ្យ៉ង់ជាក់ស្តែងនៃទិន្នន័យបញ្ចាំងគឺ៖
$$\sigma_{\text{proj}}^2 = \frac{1}{n} \sum_{i=1}^n (x^{(i)T} u)^2 = \frac{1}{n} \sum_{i=1}^n (u^T x^{(i)})(x^{(i)T} u) = u^T \left( \frac{1}{n} \sum_{i=1}^n x^{(i)} x^{(i)T} \right) u$$

កន្សោមក្នុងវង់ក្រចកគឺជា **ម៉ាទ្រីសកូវ៉ារ្យ៉ង់ជាក់ស្តែង** $\Sigma \in \mathbb{R}^{d \times d}$៖
$$\sigma_{\text{proj}}^2 = u^T \Sigma u$$

ដើម្បីធ្វើអតិបរមាកម្មលើវ៉ារ្យ៉ង់បញ្ចាំងនេះ ក្រោមលក្ខខណ្ឌកំហិតណមឯកតា $u^T u = 1$ យើងបង្កើតអនុគមន៍ឡាក្រង់ (Lagrangian)៖
$$\mathcal{L}(u, \lambda) = u^T \Sigma u - \lambda(u^T u - 1)$$

គណនាជម្រាលធៀបនឹង $u$ ហើយកំណត់ឱ្យស្មើនឹង $0$៖
$$\nabla_u \mathcal{L}(u, \lambda) = 2\Sigma u - 2\lambda u = 0 \implies \Sigma u = \lambda u$$

នេះគឺជា **សមីការតម្លៃផ្ទាល់ស្តង់ដារ (Standard Eigenvalue Equation)**! គុណនឹង $u^T$ ពីខាងឆ្វេង៖
$$u^T \Sigma u = \lambda u^T u = \lambda$$

ដូច្នេះ ដើម្បីធ្វើឱ្យវ៉ារ្យ៉ង់បញ្ចាំងមានតម្លៃអតិបរមា $u$ ត្រូវតែជា **វ៉ិចទ័រផ្ទាល់ (Eigenvector)** នៃម៉ាទ្រីសកូវ៉ារ្យ៉ង់ $\Sigma$ ដែលត្រូវគ្នាទៅនឹង **តម្លៃផ្ទាល់ធំបំផុត $\lambda_1$**។ សមាសភាគចម្បងបន្តបន្ទាប់ទៀត គឺជាវ៉ិចទ័រផ្ទាល់អរតូកូណាល់ដែលត្រូវគ្នាទៅនឹងតម្លៃផ្ទាល់រៀបតាមលំដាប់ចុះ $\lambda_2, \lambda_3, \dots$។

### ៤. លំហូរការងារក្បួនដោះស្រាយជាជំហានៗ (Optimization Workflows)

#### វដ្តទូទៅនៃក្បួនដោះស្រាយ Expectation-Maximization (EM)
ក្បួនដោះស្រាយ EM ដំណើរការឆ្លាស់គ្នារវាងជំហាន E-step និង M-step ដើម្បីបង្កើនលោការីតលទ្ធភាពនៃម៉ូដែលអថេរលាក់កំបាំង៖
1. **កំណត់តម្លៃដំបូង** នៃប៉ារ៉ាម៉ែត្រ $\theta^{(0)}$ ដោយចៃដន្យ ឬតាមក្បួនវិចារណញាណ។
2. **ធ្វើសារឡើងវិញរហូតដល់រួមចំណុះ (Convergence)**៖
   - **E-Step (Expectation)**: សម្រាប់គំរូនីមួយៗ $i \in \{1, \dots, n\}$ កំណត់ $Q_i$ ឱ្យស្មើនឹងបំណែងចែកប្រូបាប៊ីលីតេក្រោយនៃអថេរលាក់កំបាំង ដោយដឹងទិន្នន័យ និងប៉ារ៉ាម៉ែត្របច្ចុប្បន្ន៖
     $$Q_i^{(t)}(z^{(i)}) := p(z^{(i)} \mid x^{(i)}; \theta^{(t)})$$
   - **M-Step (Maximization)**: គណនាប៉ារ៉ាម៉ែត្រថ្មីដ៏ប្រសើរបំផុត $\theta^{(t+1)}$ ដោយធ្វើអតិបរមាកម្មលើតម្លៃរំពឹងទុកនៃលោការីតលទ្ធភាពរួមធៀបនឹងបំណែងចែក $Q$៖
     $$\theta^{(t+1)} := \arg \max_{\theta} \sum_{i=1}^n \sum_{z^{(i)}} Q_i^{(t)}(z^{(i)}) \log \frac{p(x^{(i)}, z^{(i)}; \theta)}{Q_i^{(t)}(z^{(i)})}$$

### ៥. ការអនុវត្តជាក់ស្តែង & ឧទាហរណ៍កូដ Python (Implementation)

#### ក. Expectation-Maximization សម្រាប់ Gaussian Mixture Models (GMM)
```python
import numpy as np

def gmm_em(X, K, max_iter=100, tol=1e-4):
    n, d = X.shape
    # កំណត់តម្លៃប៉ារ៉ាម៉ែត្រដំបូង
    phi = np.ones(K) / K
    mus = X[np.random.choice(n, K, replace=False)]
    sigmas = np.array([np.eye(d) for _ in range(K)])
    w = np.zeros((n, K))
    
    for iteration in range(max_iter):
        # E-Step: គណនាសមាជិកភាពស្រទន់ (Responsibilities)
        for j in range(K):
            diff = X - mus[j]
            inv_sigma = np.linalg.inv(sigmas[j])
            det_sigma = np.linalg.det(sigmas[j])
            exponent = -0.5 * np.sum(diff @ inv_sigma * diff, axis=1)
            # គណនាដង់ស៊ីតេ Gaussian ពហុវិមាត្រ
            w[:, j] = phi[j] * (1.0 / np.sqrt(((2*np.pi)**d) * det_sigma)) * np.exp(exponent)
            
        # ធ្វើស្តង់ដារកម្មឆ្លងកាត់ថ្នាក់ទាំងអស់សម្រាប់ w_ij
        sum_w = np.sum(w, axis=1, keepdims=True)
        w /= sum_w
        
        # M-Step: ធ្វើបច្ចុប្បន្នភាពប៉ារ៉ាម៉ែត្រ
        sum_w_j = np.sum(w, axis=0)
        phi = sum_w_j / n  # បច្ចុប្បន្នភាព Prior
        
        for j in range(K):
            # ធ្វើបច្ចុប្បន្នភាពវ៉ិចទ័រមធ្យម (មធ្យមទម្ងន់)
            mus[j] = np.sum(w[:, [j]] * X, axis=0) / sum_w_j[j]
            # ធ្វើបច្ចុប្បន្នភាពម៉ាទ្រីសកូវ៉ារ្យ៉ង់ (Outer Products ធៀបនឹងទម្ងន់)
            diff = X - mus[j]
            sigmas[j] = (diff.T @ (w[:, [j]] * diff)) / sum_w_j[j]
            
    return phi, mus, sigmas
```

#### ខ. ការកាត់បន្ថយវិមាត្រទិន្នន័យតាមរយៈ PCA (PCA Dimensionality Reduction)
```python
def pca_reduction(X, k_components):
    # ១. ការតម្រឹមកណ្តាលមធ្យម (Mean Centering)
    X_centered = X - np.mean(X, axis=0)
    
    # ២. ការធ្វើមាត្រដ្ឋានឡើងវិញ (Standardization)
    X_scaled = X_centered / np.std(X_centered, axis=0)
    
    # ៣. គណនាម៉ាទ្រីសកូវ៉ារ្យ៉ង់ជាក់ស្តែង (Covariance Matrix)
    covariance_matrix = np.cov(X_scaled, rowvar=False)
    
    # ៤. ការបំបែកតម្លៃផ្ទាល់ (Eigenvalue Decomposition)
    eigenvalues, eigenvectors = np.linalg.eigh(covariance_matrix)
    
    # តម្រៀបតម្លៃផ្ទាល់តាមលំដាប់ចុះ
    sorted_indices = np.argsort(eigenvalues)[::-1]
    top_vectors = eigenvectors[:, sorted_indices[:k_components]]
    
    # ៥. បញ្ចាំងទិន្នន័យទៅកាន់អនុលំហវិមាត្រទាប
    X_reduced = X_scaled @ top_vectors
    return X_reduced, eigenvalues[sorted_indices]
```

### ៦. កម្មវិធីអនុវត្តជាក់ស្តែង (Applications)
- **ការវិភាគទម្រង់នៃការបញ្ចេញភាគល្អិតតារាសាស្ត្រ (Astroparticle Emission Profiling)**: ការញែកបំណែងចែកបញ្ចេញពន្លឺចម្រុះដែលត្រួតស៊ីគ្នាពីប្រភពលោហធាតុផ្សេងៗគ្នា (ដូចជា ផ្កាយពុលសារ ក្វាសារ និងហ្វូតុងផ្ទៃខាងក្រោយ) ដោយគ្មានស្លាកចាត់ថ្នាក់ពិតជាមុន។
- **ការកាត់បន្ថយសំឡេងរំខាននៃទិន្នន័យវិមាត្រខ្ពស់ (High-Dimensional Data Denoising)**: ការច្រោះសំឡេងរំខានរង្វាស់ប្រេកង់ខ្ពស់ចៃដន្យ ដោយការបញ្ចាំងទិន្នន័យទៅកាន់អនុលំហចម្បងវិមាត្រទាប រួចធ្វើការកសាងទិន្នន័យឡើងវិញ។
- **ការបង្រួមវ៉ិចទ័រភាសាវិទ្យា (Linguistic Vector Compression)**: ការបង្រួមវ៉ិចទ័រពាក្យ-ឯកសារស្តើងៗដ៏ធំសម្បើម ឱ្យមកនៅត្រឹមទម្រង់តំណាងអត្ថន័យមិនទាន់ឃើញដ៏ក្រាស់ (ដូចជា ដំណាក់កាលកែច្នៃបឋមនៃ Latent Semantic Analysis / Word2Vec)។

### ៧. សំណួរត្រិះរិះពិចារណា (Reflection Questions)
1. **តួនាទីនៃភាពមិនអវិជ្ជមានក្នុងវិសមភាពហ្សង់សែន**: ហេតុអ្វីបានជាលក្ខខណ្ឌគណិតវិទ្យាទាមទារឱ្យបំណែងចែកជំនួស $Q(z)$ ត្រូវតែមិនអវិជ្ជមាន ($Q(z) \ge 0$) និងមានផលបូកស្មើ ១ ($\sum Q(z) = 1$) ទើបវិសមភាពហ្សង់សែនអាចដំណើរការបាន? តើការណ៍នេះកំណត់កម្រិតព្រំដែននៃលំហអនុគមន៍ដែល EM អាចរុករកយ៉ាងដូចម្តេច?
2. **អស្ថិរភាពនៃគោលតម្លៃផ្ទាល់ (Instability of the Eigen-Basis)**: ប្រសិនបើសំណុំទិន្នន័យមួយមានម៉ាទ្រីសកូវ៉ារ្យ៉ង់ជាក់ស្តែងដែលតម្លៃផ្ទាល់កំពូលទាំងពីរស្មើគ្នា ($\lambda_1 = \lambda_2$) តើការណ៍នេះបញ្ជាក់អ្វីខ្លះអំពីភាពតែមួយគត់នៃវ៉ិចទ័រសមាសភាគចម្បងទីមួយ $u_1$? ហេតុអ្វីបានជាស្ថានភាពនេះអាចធ្វើឱ្យក្បួនចាត់ថ្នាក់លីនេអ៊ែរខាងក្រោមដំណើរការមិនស៊ីសង្វាក់គ្នានៅពេលទិន្នន័យមានការរំខានបន្តិចបន្តួច?
3. **ការបាត់បង់ព័ត៌មាន និងស្នាមម៉ាទ្រីសកូវ៉ារ្យ៉ង់ (Covariance Trace)**: តើការគណនាស្នាម (Trace) នៃម៉ាទ្រីសកូវ៉ារ្យ៉ង់ជាក់ស្តែង $\Sigma$ អនុញ្ញាតឱ្យយើងគណនាភាគរយជាក់លាក់នៃវ៉ារ្យ៉ង់សរុបនៃសំណុំទិន្នន័យដែលត្រូវបានរក្សាទុក នៅពេលបញ្ចាំងទិន្នន័យចុះមកត្រឹម $k$ សមាសភាគយ៉ាងដូចម្តេច?
