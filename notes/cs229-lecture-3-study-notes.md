## Lecture 3: Weighted Least Squares (Supervised Learning setup & Logistic Regression)

### 1. Summary

This lecture builds a mathematically rigorous bridge between statistical theory and practical machine learning algorithms by introducing the **Maximum Likelihood Estimation (MLE)** framework. The instructor, Chris Ré, provides a formal probabilistic justification for the Least Squares cost function introduced in Lecture 2, demonstrating that minimizing the sum of squared errors is mathematically equivalent to maximizing the log-likelihood of the data under the assumption of independent and identically distributed (IID) Gaussian noise.

The lecture then transitions from continuous regression to **binary classification**. Chris Ré highlights the fundamental flaws of applying linear regression directly to classification tasks (such as decision boundary distortion caused by far-away outliers) and motivates the use of **Logistic Regression**. By running a linear combination of features through a smooth, monotonic sigmoid link function, the model outputs well-behaved probabilities. The log-likelihood of this classification model is derived and optimized via gradient ascent, revealing an elegant, universal "error-correcting" update gradient.

Finally, the lecture explores alternative optimization methods, focusing on **Newton’s Method**. Chris Ré contrasts the extremely fast, parameter-free local convergence of Newton's method with its prohibitive $O(nd^2 + d^3)$ per-step computational complexity. This comparison cements why simple, computationally lightweight algorithms like **Stochastic Gradient Descent (SGD)** remain the undisputed workhorse for scaling modern high-dimensional, large-scale machine learning models (such as Large Language Models).

### 2. Key Concepts & Definitions

- **Binary Classification**: A supervised learning task where the target label space is discrete and restricted to two outcomes, conventionally denoted as $y^{(i)} \in \{0, 1\}$ (e.g., cat vs. not cat).
- **Unbiased Noise Assumption**: The assumption that the expected value of the noise term $\epsilon^{(i)}$ is zero ($E[\epsilon^{(i)}] = 0$), implying that there is no systematic bias in the data generation process or measurements.
- **Independent and Identically Distributed (IID)**: A core modeling assumption where each noise term (or data point) is drawn independently from the same probability distribution. This allows the joint probability density of the entire dataset to factorize cleanly into a product of individual probabilities.
- **Likelihood ($L(\theta)$)**: The probability of the observed dataset as a function of the parameter vector $\theta$, holding the observed data fixed.
- **Log-Likelihood ($l(\theta)$)**: The natural logarithm of the likelihood function. It converts products into sums, preventing numerical underflow and simplifying differentiation.
- **Maximum Likelihood Estimation (MLE)**: A statistical paradigm where we select the parameters $\theta$ that maximize the likelihood (or log-likelihood) of the observed training data.
- **Link Function**: A monotonic function $g$ that maps linear model predictions ($\theta^T x$) to a restricted, non-linear output space (e.g., $(0, 1)$ for probabilities).
- **Sigmoid / Logistic Function**: A specific link function $g(z) = \frac{1}{1 + e^{-z}}$ that smoothly maps any real-valued input $z \in \mathbb{R}$ to a probability value in the interval $(0, 1)$.
- **Hessian Matrix ($H$)**: A square $(d+1) \times (d+1)$ matrix containing the second-order partial derivatives of the cost (or log-likelihood) function, capturing the local curvature of the optimization landscape.
- **Moore-Penrose Pseudo-Inverse ($H^{\dagger}$)**: A generalization of the matrix inverse used in Newton's method when the Hessian is singular (non-invertible), gracefully handling underdetermined or overdetermined parameter subspaces.

### 3. Mathematical Formulations & Derivations

#### A. Probabilistic Justification of Least Squares (MLE)

We assume the target labels are generated by a true, unobserved linear model corrupted by Gaussian noise:
$$y^{(i)} = \theta^T x^{(i)} + \epsilon^{(i)}$$
where the noise term $\epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2)$ is IID.

This implies that the conditional distribution of the target $y^{(i)}$ given the input $x^{(i)}$ and parameters $\theta$ is normally distributed around the linear prediction:
$$y^{(i)} \mid x^{(i)}; \theta \sim \mathcal{N}(\theta^T x^{(i)}, \sigma^2)$$

The probability density function (PDF) for a single training example is written as:
$$p(y^{(i)} \mid x^{(i)}; \theta) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{(y^{(i)} - \theta^T x^{(i)})^2}{2\sigma^2} \right)$$

Under the IID assumption, the joint likelihood of all $n$ training examples is the product of their individual probabilities:
$$L(\theta) = \prod_{i=1}^n p(y^{(i)} \mid x^{(i)}; \theta) = \prod_{i=1}^n \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{(y^{(i)} - \theta^T x^{(i)})^2}{2\sigma^2} \right)$$

To find the optimal $\theta$, we take the natural logarithm to obtain the log-likelihood $l(\theta)$:
$$l(\theta) = \log L(\theta) = \sum_{i=1}^n \log \left[ \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{(y^{(i)} - \theta^T x^{(i)})^2}{2\sigma^2} \right) \right]$$
$$l(\theta) = n \log \frac{1}{\sqrt{2\pi}\sigma} - \frac{1}{2\sigma^2} \sum_{i=1}^n \left( y^{(i)} - \theta^T x^{(i)} \right)^2$$

To maximize $l(\theta)$ with respect to $\theta$, the constant first term is ignored. The second term contains a negative coefficient multiplying the sum of squared errors. Thus, maximizing the log-likelihood is equivalent to minimizing the squared errors:
$$\arg\max_\theta l(\theta) = \arg\min_\theta \frac{1}{2} \sum_{i=1}^n \left( y^{(i)} - \theta^T x^{(i)} \right)^2$$

This is precisely the Least Squares cost function $J(\theta)$. **This proves that Least Squares is the Maximum Likelihood Estimator under IID Gaussian noise**.

#### B. Logistic Regression (Sigmoid Link Function & MLE)

For binary classification where $y^{(i)} \in \{0, 1\}$, we model the probability of the class labels using the linear hypothesis run through the sigmoid function:
$$h_\theta(x) = g(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}}$$

The probability of each class label is defined as:
$$P(y = 1 \mid x; \theta) = h_\theta(x)$$
$$P(y = 0 \mid x; \theta) = 1 - h_\theta(x)$$

This can be written compactly as a single Bernoulli-like probability density:
$$p(y \mid x; \theta) = (h_\theta(x))^y (1 - h_\theta(x))^{1-y}$$

Assuming $n$ IID training examples, the likelihood of the dataset is:
$$L(\theta) = \prod_{i=1}^n (h_\theta(x^{(i)}))^{y^{(i)}} (1 - h_\theta(x^{(i)}))^{1-y^{(i)}}$$

Taking the logarithm yields the log-likelihood $l(\theta)$:
$$l(\theta) = \sum_{i=1}^n \left[ y^{(i)} \log h_\theta(x^{(i)}) + (1 - y^{(i)}) \log(1 - h_\theta(x^{(i)})) \right]$$

#### Deriving the Gradient of the Log-Likelihood

To maximize $l(\theta)$, we find its gradient with respect to $\theta_j$.
First, we note a useful property of the sigmoid function:
$$g'(z) = \frac{d}{dz} \left( \frac{1}{1 + e^{-z}} \right) = \frac{e^{-z}}{(1 + e^{-z})^2} = g(z)(1 - g(z))$$

Using this derivative property and the chain rule, the partial derivative for a single example $(x, y)$ is:
$$\frac{\partial}{\partial \theta_j} l(\theta) = \left( \frac{y}{h_\theta(x)} - \frac{1-y}{1-h_\theta(x)} \right) \cdot \frac{\partial}{\partial \theta_j} h_\theta(x)$$
$$\frac{\partial}{\partial \theta_j} l(\theta) = \left( \frac{y(1-h_\theta(x)) - (1-y)h_\theta(x)}{h_\theta(x)(1-h_\theta(x))} \right) \cdot h_\theta(x)(1-h_\theta(x)) \cdot x_j$$
$$\frac{\partial}{\partial \theta_j} l(\theta) = (y - h_\theta(x))x_j$$

Summing over the entire dataset, the complete gradient of the log-likelihood is:
$$\nabla_\theta l(\theta) = \sum_{i=1}^n \left( y^{(i)} - h_\theta(x^{(i)}) \right) x^{(i)}$$

This reveals an incredibly elegant outcome: **the gradient for Logistic Regression has the exact same "error-correcting" form ($y - h(x)$) as Linear Regression**, scaled by the input features.

#### Concavity of the Logistic Log-Likelihood

The log-likelihood $l(\theta)$ is **concave**: its Hessian is
$$H = -\sum_{i=1}^n h_\theta(x^{(i)})\left(1 - h_\theta(x^{(i)})\right) x^{(i)} (x^{(i)})^T$$
which is negative semidefinite, since $h(1-h) > 0$ for every input and $v^T x x^T v = (x^T v)^2 \ge 0$. Consequently, gradient ascent and Newton's method both converge to the **global** maximum — there are no local optima to escape. This is the practical payoff of choosing the sigmoid/Bernoulli model pair.

### 4. Step-by-Step Optimization Algorithms

#### A. Gradient Ascent for Logistic Regression

Because we are *maximizing* the log-likelihood $l(\theta)$ (rather than minimizing a loss function), we use **Gradient Ascent**:

1. **Initialize** the parameter vector $\theta$ (typically randomly or to 0).
2. **Loop until convergence**:\
   Update the parameters using either Batch or Stochastic formulations:
   - **Batch Gradient Ascent**:
     $$\theta := \theta + \alpha \sum_{i=1}^n \left( y^{(i)} - h_\theta(x^{(i)}) \right) x^{(i)}$$
   - **Stochastic Gradient Ascent** (updating after each training example $i$):
     $$\theta := \theta + \alpha \left( y^{(i)} - h_{\theta^{(t)}}(x^{(i)}) \right) x^{(i)}$$
     where $\alpha$ is the learning rate.

#### B. Newton's Method (Second-Order Optimization)

Newton's Method is a second-order optimization technique that models the target function locally with a quadratic approximation to find where its derivative is zero.

##### 1. Univariate Root-Finding (1D Case)

To find the root of a function $f(\theta) = 0$:

1. **Initialize** $\theta^{(0)}$.
2. **Iterate** the update rule until convergence:
   $$\theta^{(t+1)} := \theta^{(t)} - \frac{f(\theta^{(t)})}{f'(\theta^{(t)})}$$

##### 2. Univariate Maximization

To maximize the log-likelihood $l(\theta)$, we want to find the root of its first derivative, $l'(\theta) = 0$.
Substituting $f(\theta) = l'(\theta)$ into the root-finding rule yields:
$$\theta^{(t+1)} := \theta^{(t)} - \frac{l'(\theta^{(t)})}{l''(\theta^{(t)})}$$

##### 3. Multivariate Maximization (Vector Case)

In higher dimensions where $\theta \in \mathbb{R}^{d+1}$, the scalar derivatives are replaced by the gradient vector $\nabla_\theta l(\theta)$ and the Hessian matrix $H$:
$$\theta^{(t+1)} := \theta^{(t)} - H^{-1} \nabla_\theta l(\theta^{(t)})$$
where $H \in \mathbb{R}^{(d+1) \times (d+1)}$ is the Hessian matrix, with entries defined as:
$$H_{jk} = \frac{\partial^2 l(\theta)}{\partial \theta_j \partial \theta_k}$$

### 5. Practical, System, & Optimization Trade-offs

The choice of optimization algorithm in modern machine learning is dictated by a stark trade-off between **statistical convergence speed** (number of steps needed to find the optimum) and **computational complexity per step** (flops and memory required to compute each update):

| Feature / Algorithm | Stochastic Gradient Descent (SGD) | Newton's Method |
| :--- | :--- | :--- |
| **Step Complexity (Time)** | $O(d)$ per step (or $O(Bd)$ for Minibatches) | $O(n d^2 + d^3)$ per step |
| **Memory Complexity** | $O(d)$ | $O(d^2)$ to store the Hessian matrix |
| **Convergence Rate** | Linear / Sublinear (requires many noisy steps) | Quadratic (zeroes in on optimum in very few steps) |
| **Step Size ($\alpha$) Tuning** | Highly sensitive; requires tedious scheduling/tuning | No step size parameter required; takes mathematically optimal jumps |
| **Second-Order Information** | None — uses only first derivatives (the gradient) | Full curvature via the Hessian and its inverse |
| **High-Dim Scaling ($d \gg 10^5$)** | Scales exceptionally well; standard for billion-parameter models | Completely impractical due to the $d^3$ matrix inversion cost |
| **Primary Use Cases** | Large-scale deep learning, LLMs, and internet-scale datasets | Small-scale datasets, classical statistics, and social sciences |

### 6. Weighted Least Squares & Iteratively Reweighted Least Squares (IRLS)

The lecture title's "Weighted Least Squares" refers to two related ideas that connect this lecture back to Lecture 2 and forward to Newton's method.

#### A. Weighted Least Squares (WLS)

If the noise variance differs per example (heteroscedasticity), $\epsilon^{(i)} \sim \mathcal{N}(0, \sigma_i^2)$, the MLE derivation from Section 3A goes through unchanged except each squared error is scaled by its precision:
$$J(\theta) = \frac{1}{2} \sum_{i=1}^n w^{(i)} \left( y^{(i)} - \theta^T x^{(i)} \right)^2, \quad w^{(i)} = \frac{1}{\sigma_i^2}$$
Intuition: noisier examples (large $\sigma_i$) carry less information, so they get **smaller weight** in the fit. The closed-form solution becomes the weighted normal equations $\theta = (X^T W X)^{-1} X^T W y$ with $W = \mathrm{diag}(w^{(1)}, \dots, w^{(n)})$.

#### B. IRLS: Newton's Method on Logistic Regression *is* Reweighted Least Squares

Applying Newton's method to the logistic log-likelihood produces an update that looks exactly like solving a weighted least squares problem at each iteration. With weights
$$w^{(i)} = h_\theta(x^{(i)}) \left( 1 - h_\theta(x^{(i)}) \right)$$
(the sigmoid slope at each point), the Hessian is $H = -X^T W X$ and the Newton step is equivalent to re-fitting a linear regression on "working targets" $z^{(i)} = \theta^T x^{(i)} + \frac{y^{(i)} - h_\theta(x^{(i)})}{w^{(i)}}$. Hence the name **Iteratively Reweighted Least Squares**: repeat {compute weights from current probabilities → solve weighted least squares} until convergence. This unifies the two halves of the lecture: Newton's method for logistic regression is just least squares, iterated with reweighting.

### 7. Applications

- **Classification Output Layers in LLMs**: Modern generative AI models (like Claude or ChatGPT) use a multi-class generalization of logistic regression called **softmax** as their final neural network layer. The linear output features (logits) are normalized via softmax to output probability distributions over vocabulary tokens.
- **Classical Statistical Regressions**: In biomedical research or social sciences, logistic regression is solved using Newton’s method (or its quasi-Newton approximation L-BFGS). Since datasets have small feature dimensions ($d < 100$), Newton's method is preferred because it converges instantly with zero parameter tuning.

### 8. Reflection Questions

1. **Outlier Sensitivity in Least Squares**: Geometrically, why does fitting a linear regression model to binary labels ($y \in \{0,1\}$) via least squares result in poor classification boundaries when there are extreme, easily classifiable outlier data points?
2. **Noise Model Implications**: We proved that assuming normally distributed, IID errors ($\epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2)$) mathematically leads to the least squares cost function. If we instead assumed that our errors followed a Laplace (double-exponential) distribution, how would this change the resulting MLE objective function? *(Hint: Think about how absolute error vs. squared error behaves).*
3. **The Hessian Bottleneck**: Why does Newton's method fail to scale when training modern Large Language Models? Identify the specific mathematical term in its step complexity that acts as the hardware bottleneck, and explain how modern optimizers (like AdaGrad or Adam) approximate this curvature information cheaply.

**Answer sketch for Question 2**: The Laplace density is $p(\epsilon) \propto \exp(-|\epsilon|/b)$. Running the same MLE derivation, the log-likelihood becomes $l(\theta) = \text{const} - \frac{1}{b}\sum_i |y^{(i)} - \theta^T x^{(i)}|$, so maximizing likelihood means **minimizing the sum of absolute errors** (Least Absolute Deviations, LAD) instead of squared errors. Geometrically, squared error penalizes large residuals quadratically (outliers dominate the fit), while absolute error penalizes them linearly — LAD regression is far more robust to outliers. The trade-off: the absolute-value objective is not differentiable at zero, so the clean gradient formulas of this lecture no longer apply directly.
