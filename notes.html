Lecture Notes

All available lectures for CS229 — Spring 2026

  • Lecture 1: Introduction

    SupervisedUnsupervisedReinforcement

    Course overview, ML paradigms, Mitchell's definition of machine learning, and the three pillars of ML: supervised, unsupervised, and reinforcement learning.

  • Lecture 2: Supervised Learning Setup

    Linear RegressionGradient DescentERM

    Formal setup of supervised learning with linear regression, least squares cost function, empirical risk minimization, and optimization via batch gradient descent and normal equations.

  • Lecture 3: Logistic Regression

    MLEClassificationNewton's Method

    Probabilistic justification of least squares via maximum likelihood estimation, logistic regression with the sigmoid link function, gradient ascent, and the SGD vs. Newton's method trade-off.

  • Lecture 4: Exponential Family, GLMs & Classification

    Exponential FamilyGLMSoftmaxLabel Smoothing

    A unifying framework for distributions (Bernoulli, Gaussian) via the exponential family, the three assumptions of GLMs, softmax regression for multi-class classification, and label smoothing as regularization.

  • Lecture 5: Gaussian Discriminant Analysis

    Generative LearningGDANaive BayesLaplace Smoothing

    The shift from discriminative to generative modeling: Gaussian Discriminant Analysis with closed-form parameter estimation, its connection to logistic regression, Naive Bayes for text classification, and Laplace smoothing.

  • Lecture 6: Dataset Split, ML Advice

    Bias-VarianceRidge RegressionDouble DescentCross-ValidationHyperband

    The bias-variance-noise decomposition, ridge regression and its eigenvalue stabilization, the modern double descent phenomenon, k-fold cross-validation, and compute-efficient hyperparameter tuning with Hyperband.
