About This Site

Purpose

This static portfolio collects and organizes lecture notes from Stanford CS229: Foundations and Paradigms of Machine Learning (Spring 2026). The goal is to provide a clean, searchable reference for key concepts, derivations, and workflows covered in each lecture.

Design

The site is inspired by the academicpages.github.io template and follows its core principles:

  • Clean, academic aesthetic with a sidebar navigation
  • Static HTML/CSS/JS — no dependencies or build tools
  • Responsive layout that works on desktop and mobile
  • Markdown-based source notes converted to structured HTML

Technology

LanguageHTML5, CSS3, JavaScript (ES6+)
StylingPure CSS with custom properties (no frameworks)
HostingGitHub Pages (static)
SourceMarkdown lecture notes converted to HTML
