CS229: Foundations and Paradigms of Machine Learning

Spring 2026 — Stanford University

Course Overview

CS229 is the foundational machine learning course at Stanford, covering supervised learning, unsupervised learning, reinforcement learning, and modern deep learning paradigms. The course emphasizes mathematical modeling, derivations, and formulations.

Lecture Notes

  • Lecture 1: Introduction

    Course overview, ML paradigms, Mitchell's definition

    High-level introduction to CS229 structure, grading policies, and the three pillars of machine learning: supervised, unsupervised, and reinforcement learning.

  • Lecture 2: Supervised Learning Setup

    Linear regression, ERM, gradient descent, normal equations

    Formal setup of supervised learning with linear regression, least squares cost function, and optimization via batch gradient descent and normal equations.

  • Lecture 3: Logistic Regression

    MLE, sigmoid link function, gradient ascent, Newton's method

    Probabilistic justification of least squares via maximum likelihood, logistic regression for binary classification, and the SGD vs. Newton's method trade-off.

  • Lecture 4: Exponential Family, GLMs & Classification

    Exponential family, generalized linear models, softmax regression, label smoothing

    A unifying framework for distributions (Bernoulli, Gaussian) via the exponential family, the three assumptions of GLMs, softmax regression for multi-class classification, and label smoothing as regularization.

  • Lecture 5: Gaussian Discriminant Analysis

    Generative learning, GDA, Naive Bayes, Laplace smoothing

    The shift from discriminative to generative modeling: Gaussian Discriminant Analysis with closed-form parameter estimation, its connection to logistic regression, Naive Bayes for text classification, and Laplace smoothing.

  • Lecture 6: Dataset Split, ML Advice

    Bias-variance, ridge regression, double descent, cross-validation, Hyperband

    The bias-variance-noise decomposition, ridge regression and its eigenvalue stabilization, the modern double descent phenomenon, k-fold cross-validation, and compute-efficient hyperparameter tuning with Hyperband.

  • Lecture 7: Neural Networks 1 (Architecture)

    Neural networks, activations, MLPs, residual connections, layer normalization

    From linear models to parameterized nonlinear networks: softmax and cross-entropy, why Newton's method fails under non-convexity, activation functions, MLP vectorization, residual connections, LayerNorm/RMSNorm, and convolutions.

  • Lecture 8: Neural Networks 2 (Backpropagation)

    Backpropagation, computational graphs, Jacobians, Hessian-vector products

    Reverse-mode automatic differentiation: the O(N) gradient theorem, the vector chain rule and Jacobians, backward passes for matrix multiplication (Hebbian learning) and activation layers, Hessian-vector products, and activation caching on GPUs.
