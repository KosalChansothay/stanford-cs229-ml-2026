CS336: Language Modeling from Scratch

Spring 2026 — Stanford University

Home / Courses / CS336

Course Overview

CS336 teaches language modeling (LLMs) from first principles: building the full stack by hand — tokenizers, architectures, training loops, scaling laws, and GPU-efficient systems — rather than gluing together high-level abstractions. The emphasis is on algorithmic efficiency: getting more capability out of the same compute and data.

Lecture Notes

  • Lecture 1: Overview, Tokenization

    From-scratch philosophy, efficiency, BPE, compression ratio, scaling rules

    The efficiency-first mindset (Accuracy = Efficiency × Resources), Byte-Pair Encoding from raw bytes up, tokenizer compression trade-offs, the naive O(V·L) encoder bottleneck, and Chinchilla-style scaling heuristics.

  • Lecture 2: PyTorch & Resource Accounting

    6NT FLOPs derivation, mixed precision formats, arithmetic intensity, memory bounds

    The 6NT training FLOPs derivation (2NT fwd, 4NT bwd), mixed-precision layout (BF16 weights/activations, FP32 optimizer states), arithmetic intensity limits on H100, GEMM vs element-wise memory bounds, and activation checkpointing.

  • Lecture 3: Architectures

    Pre-norm, RMSNorm, SwiGLU, RoPE embeddings, Grouped-Query Attention (GQA)

    Core modern LLM architecture choices: Pre-norm residual connections, RMSNorm memory efficiency, SwiGLU activation scaling (2/3 hidden dimension rule), Rotary Position Embeddings (RoPE), and Grouped-Query Attention (GQA).

  • Lecture 4: Attention Alternatives & Mixture of Experts

    Linear attention, State-Space Models (SSM), Gated Delta Net, Sparse Attention, MoE

    Bypassing the quadratic attention wall: Linear attention duality, SSMs (Mamba/S4), Gated Delta Net state tracking, DeepSeek Sparse Attention (DSA), and Mixture of Experts (MoE) routing and load-balancing dynamics.

  • Lecture 5: GPUs, TPUs, and FlashAttention

    HBM vs SRAM, SIMT warp execution, FP8/FP4 quantization, FlashAttention tiling

    Hardware accelerator hierarchy: HBM vs SRAM bandwidth gaps, SIMT execution and warp divergence, FP8/FP4 block-scaled quantization, and the FlashAttention algorithm (SRAM tiling and online softmax).

  • Lecture 6: Kernels, Triton, XLA

    CUDA thread hierarchy, memory coalescing, bank conflicts, Triton, compiler fusion

    Low-level GPU kernel development: CUDA thread block indexing, global memory coalescing, shared memory bank conflicts, writing block-level fused operators in Triton, and XLA/TorchInductor compiler optimization.

  • Lecture 7: Parallelism (Foundations)

    Collective communications, AllReduce, Distributed Data Parallel (DDP), Tensor Parallelism

    Foundations of distributed LLM training: Collective communication primitives (All-Reduce ring/tree), Distributed Data Parallel (DDP) gradient synchronization, and Megatron-LM column/row Tensor Parallelism (TP).

  • Lecture 8: Parallelism (Advanced)

    ZeRO-1/2/3, PyTorch FSDP, Pipeline Parallelism (1F1B), Sequence Parallelism, 3D topologies

    Scaling beyond single nodes: ZeRO memory stages (ZeRO-1/2/3) and PyTorch FSDP, Pipeline Parallelism (PP) with 1F1B scheduling and bubble minimization, Sequence Parallelism (SP), and 3D parallelism topology mapping.

  • Lecture 9: Scaling Laws (Foundations)

    Empirical power laws, Kaplan vs Chinchilla, 20:1 token ratio, IsoFLOP analysis

    Empirical scaling laws: Validation loss power laws (L(N, D) = E + A/N^α + B/D^β), Kaplan vs Chinchilla correction, the 20:1 token-to-parameter ratio, IsoFLOP profiling, and why inference economics drive overtraining.

  • Lecture 10: Inference (Execution & Optimization)

    Memory-bound decoding, KV cache arithmetic, PagedAttention (vLLM), Speculative Decoding, MLA

    Production inference systems: The memory-bound decoding wall, KV cache sizing and bandwidth consumption, vLLM PagedAttention virtual memory management, Speculative Decoding acceptance math, and DeepSeek MLA latent compression.

  • Lecture 11: Scaling Laws & Advanced Optimizers

    muP zero-shot hyperparameter transfer, WSD learning rate schedules, Muon optimizer

    Hyperparameter scaling and next-gen optimization: Maximal Update Parameterization (μP) for zero-shot LR transfer across model sizes, Warmup-Stable-Decay (WSD) schedules, and the Muon optimizer (Newton-Schulz matrix updates).

  • Lecture 12: Evaluation (Methodology & Contamination)

    Construct validity, log-likelihood vs generation, MMLU/GPQA, Chatbot Arena Elo, contamination

    Evaluating language models: Construct validity vs operational metrics, log-likelihood vs free-form generation scoring, MMLU/GSM8K/GPQA nuances, Chatbot Arena Elo rating modeling, and n-gram/embedding contamination detection.

  • Lecture 13: Data (Sources & Datasets)

    Common Crawl, C4, FineWeb-Edu, domain mixing, shadow libraries, synthetic pre-training

    Pre-training data pipelines: Web scraping realities with Common Crawl, curating datasets from C4 to FineWeb-Edu, domain mixing ratios, legal boundaries of shadow libraries, and the role of synthetic data in pre-training.

  • Lecture 14: Data (Preprocessing & Mixing)

    HTML text extraction, FastText filtering, MinHash/LSH deduplication, quality heuristics

    Data processing algorithms: HTML parsing and noise removal, FastText language identification, MinHash and Locality Sensitive Hashing (LSH) near-deduplication, classifier-based quality heuristics, and dynamic domain mixing.

  • Lecture 15: Post-Training (SFT & Preference Optimization)

    SFT mode extraction, multi-turn chat templates, RLHF with reward models, DPO loss

    Post-training alignment: Supervised Fine-Tuning (SFT) mechanics and mode extraction, multi-turn prompt templates, Bradley-Terry reward modeling in classic RLHF (PPO), and Direct Preference Optimization (DPO) closed-form loss.

  • Lecture 16: Post-Training — RLVR (Verifiable Rewards)

    RLVR in math/code, DeepSeek GRPO without critic, reward hacking, test-time compute

    The frontier of post-training: Transitioning from soft preferences to verifiable rewards (RLVR) in math/code, DeepSeek GRPO (group relative baseline without a critic), reward hacking mitigation, and test-time compute scaling.

  • Lecture 17: Alignment — Multimodality

    ViT patch tokenization, SigLIP binary loss, LLaVA connectors, cross-attention fusion

    Extending LLMs to multimodality: Vision tokenization via ViT patches, CLIP vs SigLIP pairwise binary contrastive loss, LLaVA linear projection and connector networks, cross-attention fusion (Flamingo), and visual hallucination alignment.

  • Guest Lecture: Systems and Alternative Architectures (Dan Fu)

    Prefill/decode disaggregation, Mega-Kernels, ThunderKittens CUDA library, Parse loop transformers

    Dan Fu's guest lecture on cutting-edge inference systems: Disaggregating prefill and decode clusters, full-layer Mega-Kernels, ThunderKittens hardware-aware CUDA optimization, and Parse stabilized loop transformers.
