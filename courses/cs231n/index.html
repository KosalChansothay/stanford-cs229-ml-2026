CS231N: Deep Learning for Computer Vision

Spring 2026 — Stanford University

Home / Courses / CS231N

Course Overview

CS231N is the deep learning for computer vision course: from image classification with linear classifiers through convolutional networks, backpropagation, attention and transformers, detection and segmentation, self-supervised and generative models, 3D vision, and robot learning. The emphasis is on end-to-end visual representation learning — replacing hand-engineered features with networks trained on large-scale annotated data.

Lecture Notes

  • Lecture 1: Introduction

    Visual intelligence, hierarchical processing, Top-5 error metric

    From the Cambrian Explosion to AlexNet: the convergence of algorithms, GPU compute, and large-scale annotated data, plus the Top-5 error benchmark and backpropagation calculus.

  • Lecture 2: Image Classification with Linear Classifiers

    Linear mapping, distance metrics, loss surfaces

    Linear classifiers as template matching, the L1 vs L2 distance metric geometry, k-nearest neighbors decision boundaries, and the multiclass SVM/cross-entropy loss formalism.

  • Lecture 3: Regularization and Optimization

    Optimization trajectories, regularization, conditioning

    Gradient descent variants on the loss landscape: SGD, Momentum, RMSprop and Adam trajectories, regularization as landscape smoothing, and the role of condition numbers.

  • Lecture 4: Neural Networks and Backpropagation

    Backpropagation, vanishing gradients, gate dynamics

    Computational graphs and the chain rule, forward/backward passes, vanishing gradients through saturated sigmoid gates, and why ReLU preserves gradient flow.

  • Lecture 5: Image Classification with CNNs

    Conv output shapes, parameter counts, FLOPs

    Convolutional layers as sliding receptive fields: output shape arithmetic (K, P, S, C_out), parameter and FLOPs accounting, and max-pooling downsampling.

  • Lecture 6: CNN Architectures

    Activation statistics, normalization, skip connections

    AlexNet to ResNet: VGG-style plain blocks, BatchNorm unit-variance stabilization across depth, and residual connections that enable very deep networks.

  • Lecture 7: Recurrent Neural Networks

    Sequence modeling, gate dynamics, memory cells

    Sequence modeling with RNNs: vanilla RNN gradient decay, the LSTM forget/input/output gates, and the additive cell-state gradient highway.

  • Lecture 8: Attention and Transformers

    Attention heatmaps, head specialization, O(N^2) cost

    Self-attention as token-to-token alignment: scaled dot-product attention, multi-head specialization patterns, positional encodings, and the quadratic sequence-length cost.

  • Lecture 9: Object Detection, Segmentation, Visualization

    Encoder-decoder grids, upsampling, feature maps

    Dense prediction tasks: object detection pipelines, fully convolutional segmentation with max-unpooling vs nearest-neighbor upsampling, and feature visualization.

  • Lecture 10: Video Understanding

    Voxel grids, temporal convolutions, activation tracing

    Video models: 3D convolutions over spatiotemporal voxels, receptive-field growth across layers, and tracing which frames contribute to an activation.

  • Lecture 11: Large Scale Distributed Training

    GPU clusters, memory trade-offs, all-reduce

    Training at scale: parallelism strategy matrices (DP/TP/PP/CP), GPU memory trade-offs, activation checkpointing, and communication-bandwidth constraints.

  • Lecture 12: Self-Supervised Learning

    PCA embedding space, positive/negative pairs, temperature

    Learning without labels: contrastive objectives pulling positive pairs together, embedding-space cluster formation, temperature tuning, and representation collapse.

  • Lecture 13: Generative Models 1

    Latent slices, reconstruction quality, beta trade-off

    Variational autoencoders: the ELBO objective, latent-space structure under the KL-weight beta, and the disentanglement vs reconstruction-quality trade-off.

  • Lecture 14: Generative Models 2

    Particle flows, probability density, CFG

    Iterative denoising generation: probability-flow ODEs from noise to data, noise schedule variants, and classifier-free guidance trading diversity for fidelity.

  • Lecture 15: 3D Vision

    Ray marching, memory scaling, volume density

    Representing 3D scenes: cubic memory scaling of voxel grids, point clouds and meshes, and NeRF ray-marching volume integration.

  • Lecture 16: Vision and Language

    Hypersphere embeddings, cosine proximity, batch size

    Joint vision-language embeddings: CLIP contrastive training, batch-scale effects, and compositional failure modes under subject-object reversal.

  • Lecture 17: Robot Learning

    Trajectory drift, covariate shift, expert demos

    Learning robotic control: behavior-cloning trajectory drift under covariate shift, DAgger interactive correction, and diffusion policy rollouts.

  • Lecture 18: Human-Centered AI

    Task hierarchies, sim-to-real gaps, preferences

    Human-centered considerations: dataset bias audit, sim-to-real generalization gaps, and aligning robot success with human task preferences.
