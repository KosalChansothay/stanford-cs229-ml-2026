កំណត់ចំណាំមេរៀនទាំងអស់

មេរៀនទាំងអស់ — CS229, CS336 & CS231N, និទាឃរដូវ ឆ្នាំ២០២៦

  • CS229 មេរៀនទី ១: សេចក្តីផ្តើម (Introduction)

    Supervised Unsupervised Reinforcement ភាសាខ្មែរ

    ទិដ្ឋភាពទូទៅនៃវគ្គសិក្សា ទម្រង់នៃការរៀនរបស់ម៉ាស៊ីន (ML paradigms) និយមន័យរបស់ Mitchell និងសសរស្តម្ភទាំងបីនៃ ML៖ ការរៀនដោយមានការណែនាំ ការរៀនដោយគ្មានការណែនាំ និងការរៀនបែបពង្រឹង។

  • CS229 Lecture 2: Supervised Learning Setup

    Linear RegressionGradient DescentERM

    Formal setup of supervised learning with linear regression, least squares cost function, empirical risk minimization, and optimization via batch gradient descent and normal equations.

  • CS229 Lecture 3: Logistic Regression

    MLEClassificationNewton's Method

    Probabilistic justification of least squares via maximum likelihood estimation, logistic regression with the sigmoid link function, gradient ascent, and the SGD vs. Newton's method trade-off.

  • CS229 Lecture 4: Exponential Family, GLMs & Classification

    Exponential FamilyGLMSoftmaxLabel Smoothing

    A unifying framework for distributions (Bernoulli, Gaussian) via the exponential family, the three assumptions of GLMs, softmax regression for multi-class classification, and label smoothing as regularization.

  • CS229 Lecture 5: Gaussian Discriminant Analysis

    Generative LearningGDANaive BayesLaplace Smoothing

    The shift from discriminative to generative modeling: Gaussian Discriminant Analysis with closed-form parameter estimation, its connection to logistic regression, Naive Bayes for text classification, and Laplace smoothing.

  • CS229 Lecture 6: Dataset Split, ML Advice

    Bias-VarianceRidge RegressionDouble DescentCross-ValidationHyperband

    Diagnostic workflows for machine learning projects: bias-variance trade-off, L2 regularization, the double descent phenomenon, hold-out vs. cross-validation, and multi-fidelity hyperparameter tuning via Hyperband.

  • CS229 Lecture 7: Neural Networks Architecture

    Neural NetworksNonlinearitiesVectorization

    From generalized linear models to multi-layer perceptrons: activations, expressivity, and GPU-efficient forward-pass vectorization.

  • CS229 Lecture 8: Backpropagation & Training

    BackpropagationAutodiffAdam

    Matrix calculus and computational graphs: reverse-mode autodiff, chain rule derivations, numerical stability, and adaptive gradient optimizers.

  • CS229 Lecture 9: K-Means & Gaussian Mixture Models

    ClusteringGMMLatent Variables

    Unsupervised grouping and density estimation: coordinate descent in K-Means, soft assignments, and the Gaussian Mixture Model formulation.

  • CS229 Lecture 10: Expectation-Maximization & PCA

    EM AlgorithmJensen's InequalityPCASVD

    The general EM algorithm via Jensen's inequality and evidence lower bound (ELBO), followed by Principal Component Analysis via eigen-decomposition and SVD.

  • CS229 Lecture 11: Generative Diffusion Models

    DiffusionScore MatchingSDE

    Modern generative models: forward noising process, score-based reverse sampling, denoising score matching, and classifier-free guidance.

  • CS229 Lecture 12: Foundation Models & Fine-Tuning

    Foundation ModelsLoRAPEFT

    Pre-training paradigms, in-context learning, parameter-efficient fine-tuning via Low-Rank Adaptation (LoRA), and model compression.

  • CS229 Lecture 13: Contrastive Learning & RAG

    Contrastive LearningInfoNCERAG

    Self-supervised representation learning via InfoNCE loss, multi-modal alignment, vector databases, and retrieval-augmented generation pipelines.

  • CS229 Lecture 14: Transformers & Self-Attention

    TransformersSelf-AttentionFlashAttention

    The Transformer architecture from first principles: scaled dot-product attention, multi-head projections, positional encodings, and IO complexity.

  • CS336: Language Modeling from Scratch

    CS336LLMTokenizationDistributed Systems

    All 17 lectures + guest lecture covering the entire LLM lifecycle from Byte-Pair Encoding to GPU kernels, 3D parallelism, scaling laws, and post-training alignment.

  • CS231N: Deep Learning for Computer Vision

    CS231NComputer VisionCNNsTransformersRobotics

    All 18 lectures on visual recognition: convolutional networks, Vision Transformers, object detection, generative diffusion, 3D NeRF, and robot learning.
