១. សេចក្តីសង្ខេបនៃគំនិតចម្បងៗ

មេរៀននេះផ្តោតលើសំណួរគន្លឹះដ៏សំខាន់បំផុតក្នុងវិស័យ Machine Learning៖ តើយើងគួរជ្រើសរើសម៉ូដែលបែបណាដើម្បីឱ្យវាមានសមត្ថភាពធ្វើទូទៅកម្ម (Generalization) យ៉ាងមានប្រសិទ្ធភាពខ្ពស់លើទិន្នន័យថ្មីដែលមិនធ្លាប់ឃើញពីមុន? សាស្ត្រាចារ្យបានបកស្រាយយ៉ាងលម្អិតអំពីទំនាស់ជាមូលដ្ឋានរវាង ការផ្គូផ្គងខ្វះកម្រិត (Underfitting - គម្លាតលម្អៀងខ្ពស់ / High Bias) និង ការផ្គូផ្គងហួសកម្រិត (Overfitting - វ៉ារ្យ៉ង់ខ្ពស់ / High Variance) តាមរយៈទ្រឹស្តីស្ថិតិនៃ ការបំបែកសមាសធាតុ Bias-Variance (Bias-Variance Decomposition)។

ដើម្បីដោះស្រាយបញ្ហាវ៉ារ្យ៉ង់ខ្ពស់ បច្ចេកទេស Regularization (ដោយប្រើ Ridge Regression ជាករណីសិក្សា) ត្រូវបានណែនាំដើម្បីប្តូរយកការកើនឡើងនូវ Bias បន្តិចបន្តួចជាថ្នូរនឹងការកាត់បន្ថយវ៉ារ្យ៉ង់យ៉ាងច្រើនលើសលប់។ បន្ទាប់មក មេរៀនបានភ្ជាប់ទ្រឹស្តីបុរាណទៅកាន់ បទដ្ឋានគំនិត Machine Learning ទំនើបៗ រួមមានបាតុភូត Double Descent និងការសិក្សា ImageNet-V2 ដែលលុបបំបាត់ការព្រួយបារម្ភអំពី Adaptive Overfitting។ ជាចុងក្រោយ លំហូរការងារជាក់ស្តែងដូចជា \(k\)-fold Cross-Validation និង ក្បួនដោះស្រាយ Hyperband ត្រូវបានណែនាំសម្រាប់ការលៃតម្រូវ Hyperparameter។

២. គោលគំនិតសំខាន់ៗ & និយមន័យ

  • គោលដៅនៃការធ្វើទូទៅកម្ម (Generalization): ជ្រើសរើសម៉ូដែលដែលមានស្ថិរភាព និងទស្សន៍ទាយបានត្រឹមត្រូវលើទិន្នន័យអនាគត។
  • ការផ្គូផ្គងខ្វះកម្រិត (Underfitting / High Bias): ម៉ូដែលសាមញ្ញពេក មិនអាចក្តោបក្តាប់ទម្រង់ទិន្នន័យពិតប្រាកដបាន។
  • ការផ្គូផ្គងហួសកម្រិត (Overfitting / High Variance): ម៉ូដែលស្មុគស្មាញជ្រុល រៀនទាំងសំឡេងរំខានចៃដន្យ (Random Noise) នៃទិន្នន័យបង្វឹក។
  • ការអន្តរគ្រិត (Interpolation): ស្ថានភាពដែលម៉ូដែលកាត់កាត់គ្រប់ចំណុចទិន្នន័យបង្វឹកដោយគ្មានកំហុស (Zero training loss)។
  • សំឡេងរំខានមិនអាចជៀសវាងបាន (\(\sigma^2\) - Unavoidable Noise): វ៉ារ្យ៉ង់ខាងក្នុងនៃទិន្នន័យដែលគ្មានក្បួនដោះស្រាយណាអាចលុបបំបាត់បាន។
  • បច្ចេកទេស Regularization: ការបន្ថែមទណ្ឌកម្មលើទំហំប៉ារ៉ាម៉ែត្រដើម្បីកាត់បន្ថយវ៉ារ្យ៉ង់ និងទប់ស្កាត់ Overfitting។
  • សុពលកម្មខ្វែង \(k\)-ផ្នត់ (\(k\)-fold Cross-Validation): វិធីសាស្ត្របែងចែកទិន្នន័យជា \(k\) ផ្នត់ ដើម្បីវាយតម្លៃ Hyperparameter ដោយមិនធ្វើឱ្យធ្លាយទិន្នន័យតេស្ត។
  • បាតុភូតចុះទ្វេដង (Double Descent): បាតុភូតទំនើបដែលកំហុសតេស្តធ្លាក់ចុះជាលើកទីពីរ ហួសពីកម្រិតព្រំដែនអន្តរគ្រិត (\(d = n\))។

៣. ការបំបែកសមាសធាតុ Bias-Variance (Mathematical Derivation)

ដំណើរការបង្កើតទិន្នន័យ៖ \(y = h^*(x) + \epsilon\) ដែល \(\mathbb{E}[\epsilon] = 0\) និង \(\text{Var}(\epsilon) = \sigma^2\)។

តម្លៃរំពឹងទុកនៃកំហុសតេស្តអាចបំបែកជា ៣ សមាសភាគឯករាជ្យពីគ្នា៖

\[\mathbb{E}_{S, \epsilon} \left[ (h_S(x) - y)^2 \right] = \sigma^2 + \text{Bias}(h_S(x))^2 + \text{Var}(h_S(x))\]
  • Unavoidable Noise: \(\sigma^2 = \mathbb{E}[\epsilon^2]\)
  • Bias Squared: \(\text{Bias}(h_S(x))^2 = (\bar{h}(x) - h^*(x))^2\)
  • Variance: \(\text{Var}(h_S(x)) = \mathbb{E}_S \left[ (h_S(x) - \bar{h}(x))^2 \right]\)

៤. Ridge Regression & ក្រាហ្វិកអន្តរកម្ម

អនុគមន៍គោលដៅ Ridge Regression (\(L_2\) Regularization)៖

\[J(\theta) = \frac{1}{2} \|X\theta - y\|_2^2 + \frac{\rho}{2} \|\theta\|_2^2\]

រូបមន្តប៉ារ៉ាម៉ែត្រទម្រង់បិទជិត៖

\[\theta_{\text{ridge}} = (X^T X + \rho I)^{-1} X^T y\]

ការបូកបន្ថែម \(\rho I\) ជួយរំកិលតម្លៃផ្ទាល់ \(\lambda_i \to \lambda_i + \rho\) ធានាថាម៉ាទ្រីសតែងតែមានច្រាស (\(\lambda_{\min} \ge \rho > 0\)) និងទប់ស្កាត់ការប្រែប្រួលវ៉ារ្យ៉ង់ជ្រុល។

រូបភាព៖ ការប្តូរផលប្រយោជន៍រវាង Bias និង Variance ក្នុងស្ថិតិបុរាណ។

រូបភាព៖ បាតុភូតចុះទ្វេដង (Double Descent) ក្នុងយុគសម័យ Deep Learning ទំនើប។

៥. ក្បួនដោះស្រាយ Hyperband (Successive Halving)

Hyperband Pseudocode (Simplified Successive Halving Round):
------------------------------------------------------------
ធាតុចូល: M (សំណុំនៃការកំណត់ Hyperparameter ចៃដន្យ ឧទាហរណ៍៖ តម្លៃនៃ rho)
        R (កញ្ចប់ថវិកាគណនាដំបូង ឧទាហរណ៍៖ 5 epochs សម្រាប់ការកំណត់នីមួយៗ)

ដរាបណា size(M) > 1:
    ១. ដំណើរការបង្វឹកគ្រប់ការកំណត់ទាំងអស់ក្នុង M ចំនួន R ជំហាន
    ២. វាយតម្លៃការកំណត់នីមួយៗលើសំណុំ Dev / Validation
    ៣. តម្រៀបការកំណត់ទាំងអស់តាមលំដាប់ពិន្ទុ Dev loss
    ៤. កាត់ចោល 50% ផ្នែកខាងក្រោម (ការកំណត់ដែលខ្សោយជាងគេ)
    ៥. បង្កើនទ្វេដងនូវជំហានបង្វឹកសម្រាប់បេក្ខជនដែលនៅសល់៖ R := 2 * R
    ៦. M := បេក្ខជនដែលនៅសល់ (50% ផ្នែកខាងលើ)
