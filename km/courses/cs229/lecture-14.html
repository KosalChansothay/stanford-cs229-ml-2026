មេរៀនទី ១៤: ស្ថាបត្យកម្ម Transformers និងការរៀនក្នុងបរិបទ (Transformers & In-Context Learning)

Stanford CS229 — ស្ថាបត្យកម្មម៉ូដែលភាសាធំៗ (LLMs), Self-Attention និងការគណនាលើផ្នែករឹង

ទំព័រដើម / វគ្គសិក្សា / CS229 / មេរៀនទី ១៤

១. សេចក្តីសង្ខេបនៃគំនិតចម្បងៗ

មេរៀននេះបង្ហាញអំពីស្ថាបត្យកម្ម និងគំរូនីតិវិធីប្រូបាប៊ីលីតេដែលទ្រទ្រង់ដល់ ម៉ូដែលភាសាធំៗ (LLMs) ទំនើប។ ដោយចាប់ផ្តើមពី Tokenization (BPE) និងការបញ្ជូនទៅកាន់លំហ Embeddings មេរៀនបានបង្កើតជាផ្លូវការនូវគំរូទស្សន៍ទាយពាក្យបន្ទាប់តាមរយៈ Negative Log-Likelihood / Cross-Entropy Loss។

មេរៀនពិនិត្យលម្អិតលើយន្តការ Self-Attention និងទម្រង់ម៉ាទ្រីសរបស់វា, ការប្រើប្រាស់ Causal Masking (\(-\infty\)) ដើម្បីទប់ស្កាត់ការលេចធ្លាយព័ត៌មានអនាគត, Multi-Head Attention (MHA) និងមូលហេតុដែលការឆ្លាស់គ្នារវាង Attention និង MLPs ផ្តល់នូវ Inductive Bias ដ៏ល្អបំផុត។ នៅចុងបញ្ចប់ មេរៀនបានវិភាគលើឧបសគ្គស្ទះនៃការគណនា \(O(T^2)\) និងដំណោះស្រាយបំបែកប្លុកលើ SRAM តាមរយៈ FlashAttention។

២. គោលគំនិតសំខាន់ៗ & និយមន័យ

  • Autoregressive Modeling: ការបង្កើតគំរូភាសាដោយទស្សន៍ទាយម្តងមួយ Token តាមលំដាប់ផ្អែកលើប្រវត្តិនៃ Token មុនៗ។
  • Subword Tokenization (BPE): ការបំបែកពាក្យទៅជាចំណែក Subwords ដើម្បីបញ្ចៀសបញ្ហាពាក្យក្រៅវាក្យសព្ទ (OOV) និងកាត់បន្ថយប្រវែងលំដាប់។
  • Logits & Softmax: តម្លៃទិន្នផលដើម \(U_t\) ត្រូវបានបម្លែងទៅជាការបែងចែកប្រូបាប៊ីលីតេត្រឹមត្រូវតាមរយៈអនុគមន៍ Softmax។
  • Causal Masking: ម៉ាទ្រីសត្រីកោណខាងលើដែលដាក់តម្លៃ \(-\infty\) លើទីតាំង \(j > t\) ដើម្បីធានាថា \(P_{t, j} = 0\) សម្រាប់ Token អនាគត។
  • FlashAttention: ក្បួនដោះស្រាយ Hardware-Aware Tiling ដែលគណនា Attention លើ GPU SRAM ដោយកាត់បន្ថយការអាន/សរសេរ HBM ពី \(O(T^2)\) មកត្រឹម \(O(T)\)។

៣. រូបមន្តគណិតវិទ្យានៃ Causal Self-Attention

ការគណនាក្នុងទម្រង់ម៉ាទ្រីស៖

\[H^{\text{out}} = \text{softmax}\left( \frac{Q K^T}{\sqrt{d_h}} + M \right) V\]

ដែល \(M\) គឺជាម៉ាទ្រីស Causal Mask៖

\[M_{i, j} = \begin{cases} 0 & j \le i \\ -\infty & j > i \end{cases}\]

រូបភាព៖ កម្តៅប្រូបាប៊ីលីតេនៃ Causal Attention ដែលបិទខ្ទប់ព័ត៌មានអនាគត។

៤. ភាពស្មុគស្មាញ និងដំណោះស្រាយ FlashAttention

ភាពស្មុគស្មាញនៃការគណនា និងទំហំផ្ទុកនៃស្តង់ដារ Attention គឺ \(O(T^2)\) ដែលក្លាយជាឧបសគ្គធ្ងន់ធ្ងរនៅពេលប្រវែង Context \(T\) កើនឡើងដល់រាប់ម៉ឺន ឬរាប់លាន Tokens។

FlashAttention ប្រើប្រាស់ GPU SRAM ដែលជា On-Chip Memory ល្បឿនលឿន ដើម្បីគណនា Online Softmax ដោយកាត់បន្ថយការផ្ទេរទិន្នន័យលើ GPU HBM មកត្រឹមលីនេអ៊ែរ \(O(T)\)។

រូបភាព៖ មាត្រដ្ឋានអង្គចងចាំនៃស្តង់ដារ Attention ធៀបនឹង FlashAttention។
