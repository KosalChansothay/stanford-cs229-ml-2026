មេរៀនទី ៣: Logistic Regression

Stanford CS229 — មូលដ្ឋានគ្រឹះ និងទម្រង់នៃការរៀនរបស់ម៉ាស៊ីន

ទំព័រដើម / វគ្គសិក្សា / CS229 / មេរៀនទី ៣

១. សេចក្តីសង្ខេបនៃគំនិតចម្បងៗ

មេរៀននេះផ្តោតសំខាន់លើការភ្ជាប់ទំនាក់ទំនងយ៉ាងស៊ីជម្រៅរវាង ស្ថិតិប្រូបាប៊ីលីតេ (Probability Statistics) និង ក្បួនដោះស្រាយបង្កើនប្រសិទ្ធភាពក្នុងការរៀនរបស់ម៉ាស៊ីន (Machine Learning Optimization Algorithms)។ ដំបូងបង្អស់ សាស្ត្រាចារ្យ Chris Ré បានផ្តល់នូវមូលដ្ឋានគ្រឹះយុត្តិកម្មតាមបែបប្រូបាប៊ីលីតេយ៉ាងរឹងមាំសម្រាប់ មុខងារថ្លៃដើម Least Squares ពីមេរៀនទី ២ ដោយបង្ហាញថា ការកាត់បន្ថយផលបូកការេនៃកំហុសលំអៀង គឺដូចគ្នាបេះបិទទៅនឹងការធ្វើអតិបរមាកម្មលើលទ្ធភាព (Log-Likelihood) ក្រោមការសន្មតថាទិន្នន័យមានកំហុសរំខាន Gaussian ដែលមានលក្ខណៈឯករាជ្យ និងបំណែងចែកដូចគ្នា (IID Gaussian noise)។

បន្ទាប់មក មេរៀនបានផ្លាស់ប្តូរទិសដៅពីការវិភាគតម្រែតម្រង់ជាលេខបន្តបន្ទាប់ ទៅកាន់ ការធ្វើចំណាត់ថ្នាក់ទ្វេភាគ (Binary Classification)។ សាស្ត្រាចារ្យបានគូសបញ្ជាក់ពីចំណុចខ្វះខាតគ្រឹះនៃការយក Linear Regression មកប្រើដោយផ្ទាល់លើបញ្ហាចំណាត់ថ្នាក់ (ដូចជាការបង្ខូចទ្រង់ទ្រាយព្រំដែនសម្រេចចិត្តដោយសារតែទិន្នន័យ Outliers នៅឆ្ងាយ) ហើយបានណែនាំនូវ ការវិភាគតម្រែតម្រង់ឡូជីស្ទីក (Logistic Regression)។ តាមរយៈការបញ្ជូនលទ្ធផលបន្សំលីនេអ៊ែរនៃ Features ឆ្លងកាត់ អនុគមន៍ភ្ជាប់ Sigmoid ម៉ូដែលនេះអាចបញ្ចេញតម្លៃប្រូបាប៊ីលីតេត្រឹមត្រូវចន្លោះពី ០ ដល់ ១។ ការទាញដេរីវេ Log-Likelihood នៃម៉ូដែលចំណាត់ថ្នាក់នេះ និងការបង្កើនប្រសិទ្ធភាពតាមរយៈ Gradient Ascent បានបង្ហាញនូវលទ្ធផលគួរឱ្យភ្ញាក់ផ្អើលមួយ៖ ទម្រង់ជម្រាលកែកំហុសមានទម្រង់រូបមន្ត \(y - h(x)\) ដូចគ្នាទាំងស្រុងទៅនឹង Linear Regression!

ជាចុងក្រោយ មេរៀនបានស្វែងយល់លើវិធីសាស្ត្របង្កើនប្រសិទ្ធភាពលំដាប់ទីពីរ គឺ វិធីសាស្ត្រញូតុន (Newton's Method)។ សាស្ត្រាចារ្យ Chris Ré បានប្រៀបធៀបល្បឿននៃការរួមគ្នាក្នុងកម្រិតការ៉េដ៏លឿនបំផុតរបស់ Newton's Method ទៅនឹងភាពស្មុគស្មាញនៃការគណនាកម្រិតធ្ងន់ \(O(nd^2 + d^3)\) ក្នុងមួយជំហាន ដែលពន្យល់ពីមូលហេតុដែលក្បួនដោះស្រាយសាមញ្ញ និងស្រាលដូចជា SGD នៅតែជាកម្លាំងស្នូលក្នុងការពង្រីកមាត្រដ្ឋានម៉ូដែលធំៗទំនើបៗ។

២. គោលគំនិតសំខាន់ៗ & និយមន័យ

  • ការធ្វើចំណាត់ថ្នាក់ទ្វេភាគ (Binary Classification): កិច្ចការរៀនដោយមានការណែនាំដែលលំហស្លាកសម្គាល់គោលដៅគឺជាតម្លៃដាច់ដោយឡែកកំណត់ត្រឹមពីរ តាមអនុសញ្ញាកំណត់ដោយ \(y^{(i)} \in \{0, 1\}\)។
  • ការសន្មតកំហុសរំខានគ្មានលំអៀង (Unbiased Noise Assumption): ការសន្មតថាតម្លៃរំពឹងទុកនៃកំហុសរំខាន \(\epsilon^{(i)}\) ស្មើនឹងសូន្យ (\(E[\epsilon^{(i)}] = 0\))។
  • ឯករាជ្យ និងបំណែងចែកដូចគ្នា (IID): ការសន្មតគំរូស្នូលដែលទិន្នន័យ ឬកំហុសរំខាននីមួយៗត្រូវបានទាញចេញដោយឯករាជ្យពីបំណែងចែកប្រូបាប៊ីលីតេដូចគ្នា។
  • អនុគមន៍លទ្ធភាព (Likelihood, \(L(\theta)\)): ប្រូបាប៊ីលីតេនៃសំណុំទិន្នន័យដែលបានសង្កេត គិតជាអនុគមន៍នៃវ៉ិចទ័រប៉ារ៉ាម៉ែត្រ \(\theta\)។
  • អនុគមន៍ Log-Likelihood (\(l(\theta)\)): អនុគមន៍លោការីតធម្មជាតិនៃ Likelihood ដែលបំប្លែងផលគុណឱ្យទៅជាផលបូក និងសម្រួលដល់ការគណនាដេរីវេ។
  • ការប៉ាន់ស្មានលទ្ធភាពអតិបរមា (Maximum Likelihood Estimation - MLE): គោលការណ៍ស្ថិតិដែលជ្រើសរើសប៉ារ៉ាម៉ែត្រ \(\theta\) ណាដែលធ្វើឱ្យ Log-Likelihood នៃទិន្នន័យសង្កេតមានតម្លៃអតិបរមា។
  • អនុគមន៍ភ្ជាប់ (Link Function): អនុគមន៍ម៉ូណូតូន \(g\) ដែលផ្គូផ្គងតម្លៃទស្សន៍ទាយលីនេអ៊ែរ (\(\theta^T x\)) ទៅកាន់លំហធាតុចេញមានព្រំដែនកំណត់ (ចន្លោះ \((0, 1)\) សម្រាប់ប្រូបាប៊ីលីតេ)។
  • អនុគមន៍ Sigmoid / Logistic Function: អនុគមន៍ភ្ជាប់ \(g(z) = \frac{1}{1 + e^{-z}}\) ដែលបម្លែងតម្លៃពិត \(z \in \mathbb{R}\) ទៅជាតម្លៃប្រូបាប៊ីលីតេក្នុងចន្លោះ \((0, 1)\) យ៉ាងរលូន។
  • ម៉ាទ្រីស Hessian (\(H\)): ម៉ាទ្រីសការេវិមាត្រ \((d+1) \times (d+1)\) នៃដេរីវេដោយផ្នែកលំដាប់ទីពីរ ដែលឆ្លុះបញ្ចាំងពីកម្រិតកោង (Curvature) នៃមុខងារគោលដៅ។
  • ម៉ាទ្រីសច្រាសក្លែងក្លាយ Moore-Penrose (\(H^{\dagger}\)): ទម្រង់ទូទៅនៃម៉ាទ្រីសច្រាសដែលប្រើក្នុង Newton's Method នៅពេលដែល Hessian មិនអាចច្រាសបាន (Singular)។

៣. រូបមន្តគណិតវិទ្យា និងការទាញសមីការ

ក. មូលដ្ឋានគ្រឹះយុត្តិកម្មតាមបែបប្រូបាប៊ីលីតេនៃ Least Squares (MLE)

យើងសន្មតថាស្លាកសម្គាល់គោលដៅត្រូវបានបង្កើតឡើងដោយម៉ូដែលលីនេអ៊ែរបូកនឹងកំហុសរំខាន Gaussian៖

\[y^{(i)} = \theta^T x^{(i)} + \epsilon^{(i)}, \quad \epsilon^{(i)} \sim \mathcal{N}(0, \sigma^2) \text{ (IID)}\]

នាំឱ្យអនុគមន៍ដង់ស៊ីតេប្រូបាប៊ីលីតេមានទម្រង់៖

\[p(y^{(i)} \mid x^{(i)}; \theta) = \frac{1}{\sqrt{2\pi}\sigma} \exp\left( -\frac{(y^{(i)} - \theta^T x^{(i)})^2}{2\sigma^2} \right)\]

អនុគមន៍ Log-Likelihood នៃសំណុំទិន្នន័យទាំងមូលគឺ៖

\[l(\theta) = \log \prod_{i=1}^n p(y^{(i)} \mid x^{(i)}; \theta) = n \log \frac{1}{\sqrt{2\pi}\sigma} - \frac{1}{2\sigma^2} \sum_{i=1}^n \left( y^{(i)} - \theta^T x^{(i)} \right)^2\]

ដូច្នេះ ការធ្វើអតិបរមាកម្មលើ \(l(\theta)\) គឺដូចគ្នាបេះបិទទៅនឹងការកាត់បន្ថយផលបូកការេនៃកំហុស (Least Squares)៖

\[\arg\max_\theta l(\theta) = \arg\min_\theta \frac{1}{2} \sum_{i=1}^n \left( y^{(i)} - \theta^T x^{(i)} \right)^2 = \arg\min_\theta J(\theta)\]

ខ. ការវិភាគតម្រែតម្រង់ឡូជីស្ទីក (Sigmoid Link Function & MLE)

សម្រាប់ \(y \in \{0, 1\}\) យើងកំណត់៖

\[h_\theta(x) = g(\theta^T x) = \frac{1}{1 + e^{-\theta^T x}}\] \[P(y = 1 \mid x; \theta) = h_\theta(x), \quad P(y = 0 \mid x; \theta) = 1 - h_\theta(x)\]

សរសេររួមគ្នាតាមទម្រង់ Bernoulli៖

\[p(y \mid x; \theta) = (h_\theta(x))^y (1 - h_\theta(x))^{1-y}\]

អនុគមន៍ Log-Likelihood គឺ៖

\[l(\theta) = \sum_{i=1}^n \left[ y^{(i)} \log h_\theta(x^{(i)}) + (1 - y^{(i)}) \log(1 - h_\theta(x^{(i)})) \right]\]

ការទាញដេរីវេនៃ Log-Likelihood

ដោយសារ \(g'(z) = g(z)(1 - g(z))\) ការធ្វើដេរីវេតាមវិធានច្រវាក់នាំឱ្យទទួលបាន៖

\[\frac{\partial}{\partial \theta_j} l(\theta) = (y - h_\theta(x))x_j \implies \nabla_\theta l(\theta) = \sum_{i=1}^n \left( y^{(i)} - h_\theta(x^{(i)}) \right) x^{(i)}\]

ជម្រាលនេះមានទម្រង់កែកំហុស \((y - h(x))\) ដូចគ្នាទៅនឹង Linear Regression!

ភាពផតនៃ Logistic Log-Likelihood (Concavity)

ម៉ាទ្រីស Hessian នៃ \(l(\theta)\) គឺ៖

\[H = -\sum_{i=1}^n h_\theta(x^{(i)})\left(1 - h_\theta(x^{(i)})\right) x^{(i)} (x^{(i)})^T\]

ដែលជាម៉ាទ្រីសអវិជ្ជមានពាក់កណ្តាលកំនត់ (Negative Semidefinite) ធានាថា \(l(\theta)\) ជាអនុគមន៍ផត ហើយការបង្កើនប្រសិទ្ធភាពនឹងរួមគ្នាមកកាន់ចំណុចអតិបរមាសកល (Global Maximum) ជានិច្ច។

៤. ក្បួនដោះស្រាយបង្កើនប្រសិទ្ធភាពជាជំហានៗ

ក. Gradient Ascent សម្រាប់ Logistic Regression

ដោយសារយើងចង់ធ្វើអតិបរមាកម្មលើ \(l(\theta)\) យើងប្រើប្រាស់ Gradient Ascent (សញ្ញាបូក)៖

  • Batch Gradient Ascent: \[\theta := \theta + \alpha \sum_{i=1}^n \left( y^{(i)} - h_\theta(x^{(i)}) \right) x^{(i)}\]
  • Stochastic Gradient Ascent (SGD): \[\theta := \theta + \alpha \left( y^{(i)} - h_{\theta^{(t)}}(x^{(i)}) \right) x^{(i)}\]

ឧទាហរណ៍គំរូតូចជាក់ស្តែង

ឧបមាចំណុចទិន្នន័យ \((x, y) = (2, 1)\) ជាមួយ \(x_0 = 1\) នាំឱ្យ \(x = \begin{bmatrix} 1 \\ 2 \end{bmatrix}\) ចាប់ផ្តើមពី \(\theta = \begin{bmatrix} 0 \\ 0 \end{bmatrix}\) និង \(\alpha = 0.1\)៖

  1. ទស្សន៍ទាយ៖ \(h_\theta(x) = g(0) = 0.5\)
  2. កំហុស៖ \(y - h_\theta(x) = 1 - 0.5 = 0.5\)
  3. បច្ចុប្បន្នភាព៖ \(\theta := \begin{bmatrix} 0 \\ 0 \end{bmatrix} + 0.1 \times 0.5 \times \begin{bmatrix} 1 \\ 2 \end{bmatrix} = \begin{bmatrix} 0.05 \\ 0.1 \end{bmatrix}\)
  4. លទ្ធផលថ្មី៖ \(h_\theta(x) = g(0.25) \approx 0.562\) (ប្រូបាប៊ីលីតេរំកិលខិតជិតស្លាកពិត ១)

ខ. វិធីសាស្ត្រញូតុន (Newton's Method)

វិធីសាស្ត្រលំដាប់ទីពីរដែលប្រើប្រាស់កម្រិតកោង (Curvature) នៃអនុគមន៍ដើម្បីលោតទៅកាន់ចំណុចអតិបរមា៖

\[\theta^{(t+1)} := \theta^{(t)} - H^{-1} \nabla_\theta l(\theta^{(t)})\]

ដែល \(H_{jk} = \frac{\partial^2 l(\theta)}{\partial \theta_j \partial \theta_k}\) គឺជាធាតុនៃម៉ាទ្រីស Hessian។

៥. តុល្យភាពជាក់ស្តែង ប្រព័ន្ធ និងការបង្កើនប្រសិទ្ធភាព

លក្ខណៈពិសេស Stochastic Gradient Descent (SGD) វិធីសាស្ត្រញូតុន (Newton's Method)
ភាពស្មុគស្មាញពេលវេលាក្នុងមួយជំហាន \(O(d)\) (ឬ \(O(Bd)\) សម្រាប់ Minibatch) \(O(n d^2 + d^3)\)
ទំហំអង្គចងចាំ (Memory) \(O(d)\) \(O(d^2)\) សម្រាប់ផ្ទុក Hessian
អត្រានៃការរួមគ្នា Linear / Sublinear (ជំហានច្រើន) Quadratic (ជំហានតិចតួចបំផុត)
ការលៃតម្រូវ Step Size (\(\alpha\)) ទាមទារការកំណត់កាលវិភាគល្អិតល្អន់ មិនត្រូវការ \(\alpha\) ឡើយ
ការពង្រីកលើវិមាត្រខ្ពស់ (\(d \gg 10^5\)) ពង្រីកបានយ៉ាងល្អឥតខ្ចោះ (ស្តង់ដារ LLMs) មិនអាចអនុវត្តបាន (ថ្លៃដើម \(d^3\))

៦. Weighted Least Squares & IRLS

ក. Weighted Least Squares (WLS)

នៅពេលកំហុសរំខានមានកម្រិតប្រែប្រួលខុសគ្នា \(\epsilon^{(i)} \sim \mathcal{N}(0, \sigma_i^2)\) នោះទិន្នន័យនីមួយៗត្រូវបានថ្លឹងទម្ងន់ដោយ \(w^{(i)} = \frac{1}{\sigma_i^2}\)៖

\[J(\theta) = \frac{1}{2} \sum_{i=1}^n w^{(i)} \left( y^{(i)} - \theta^T x^{(i)} \right)^2 \implies \theta = (X^T W X)^{-1} X^T W y\]

ខ. IRLS: Newton's Method លើ Logistic Regression គឺជា Reweighted Least Squares

ការអនុវត្ត Newton's Method លើ Logistic Regression គឺដូចគ្នាបេះបិទទៅនឹងការដោះស្រាយ Weighted Least Squares ម្តងហើយម្តងទៀត ជាមួយនឹងទម្ងន់ \(w^{(i)} = h_\theta(x^{(i)})(1 - h_\theta(x^{(i)}))\)។ ដំណើរការនេះត្រូវបានគេហៅថា Iteratively Reweighted Least Squares (IRLS)។

៧. កម្មវិធីអនុវត្តជាក់ស្តែង

  • ស្រទាប់បញ្ចេញលទ្ធផលចំណាត់ថ្នាក់ក្នុង LLMs (Softmax Output Layers): ម៉ូដែលភាសាធំៗប្រើប្រាស់ទម្រង់ពហុថ្នាក់នៃ Logistic Regression (Softmax) ជាស្រទាប់ចុងក្រោយដើម្បីទស្សន៍ទាយ Token បន្ទាប់។
  • ការវិភាគស្ថិតិក្នុងវិស័យជីវវេជ្ជសាស្ត្រ: ក្នុងទិន្នន័យដែលមានចំនួន Features តូច (\(d < 100\)) Newton's Method ឬ L-BFGS ត្រូវបានពេញចិត្តបំផុតព្រោះវារួមគ្នាភ្លាមៗដោយមិនបាច់លៃតម្រូវ Learning Rate។

៨. សំណួរត្រិះរិះពិចារណា

  1. ភាពរងប្រតិកម្មចំពោះ Outliers ក្នុង Least Squares: ហេតុអ្វីបានជា Linear Regression ផ្តល់ព្រំដែនសម្រេចចិត្តមិនល្អលើទិន្នន័យចំណាត់ថ្នាក់នៅពេលមាន Outlier ឆ្ងាយខ្លាំង ហើយហេតុអ្វីបានជា Logistic Regression ជៀសផុតពីបញ្ហានេះ?
  2. អត្ថន័យនៃគំរូកំហុសរំខាន: ប្រសិនបើយើងសន្មតថាកំហុសរំខានដើរតាមបំណែងចែក Laplace (\(p(\epsilon) \propto e^{-|\epsilon|/b}\)) ជំនួសឱ្យ Gaussian តើគោលដៅ MLE នឹងផ្លាស់ប្តូរទៅជាទម្រង់ណា? (ចម្លើយ៖ Least Absolute Deviations - LAD)។
  3. បញ្ហារាំងស្ទះនៃម៉ាទ្រីស Hessian: ហេតុអ្វីបានជា Newton's Method មិនអាចប្រើសម្រាប់ការហ្វឹកហាត់ LLM? តើតួគណិតវិទ្យាណាដែលជាឧបសគ្គផ្នែករឹង (ចម្លើយ៖ \(O(d^3)\) សម្រាប់បញ្ច្រាសម៉ាទ្រីស និង \(O(d^2)\) សម្រាប់ផ្ទុក Memory)?
