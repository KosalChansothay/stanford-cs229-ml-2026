Stanford CS229 — មូលដ្ឋានគ្រឹះ និងទម្រង់នៃការរៀនរបស់ម៉ាស៊ីន

១. សេចក្តីសង្ខេបនៃគំនិតចម្បងៗ

មេរៀននេះណែនាំអំពី អម្បូរបំណែងចែកអិចស្ប៉ូណង់ស្យែល (Exponential Family of Distributions) ដែលជាក្របខ័ណ្ឌគណិតវិទ្យាបង្រួបបង្រួមដ៏មានឥទ្ធិពលបំផុតមួយ សម្រាប់តភ្ជាប់ម៉ូដែល Machine Learning បុរាណជាច្រើនដែលបានសិក្សាក្នុងវគ្គនេះ។ សាស្ត្រាចារ្យ Chris Ré បានបង្ហាញថា បំណែងចែកកំហុសទូទៅជាច្រើន (ដូចជា Bernoulli សម្រាប់ទិន្នន័យទ្វេភាគ និង Gaussian សម្រាប់ទិន្នន័យបន្តបន្ទាប់) សុទ្ធសឹងតែជាករណីពិសេសនៃអម្បូរអិចស្ប៉ូណង់ស្យែលនេះទាំងអស់។

ផ្អែកលើគ្រឹះដ៏រឹងមាំនេះ មេរៀនបានណែនាំអំពី គំរូលីនេអ៊ែរទូទៅ (Generalized Linear Models - GLMs) ដែលផ្តល់នូវរូបមន្តរៀបចំ ៣ ជំហានដ៏ច្បាស់លាស់ក្នុងការកសាងម៉ូដែលទស្សន៍ទាយសម្រាប់ប្រភេទបញ្ហាស្ទើរតែទាំងអស់ក្នុងពិភពពិត។ មេរៀនបញ្ចប់ដោយការផ្តោតលើក្បួនដោះស្រាយចំណាត់ថ្នាក់ដ៏មានសារៈសំខាន់បំផុតក្នុងវិស័យឧស្សាហកម្មបច្ចុប្បន្ន គឺ ការវិភាគតម្រែតម្រង់ Softmax (Softmax Regression) សម្រាប់ការធ្វើចំណាត់ថ្នាក់ពហុថ្នាក់ (Multi-Class Classification)។ សាស្ត្រាចារ្យបានភ្ជាប់គំនិតនេះទៅនឹងស្ថាបត្យកម្ម Deep Learning ទំនើបៗ រួមទាំងយន្តការ Attention Heads ក្នុងម៉ូដែល Transformer (ដូចជា GPT-2) និងបានណែនាំបច្ចេកទេស Regularization ដ៏មានប្រសិទ្ធភាពគឺ Label Smoothing។

២. គោលគំនិតសំខាន់ៗ & និយមន័យ

  • អម្បូរបំណែងចែកអិចស្ប៉ូណង់ស្យែល (Exponential Family): ថ្នាក់នៃបំណែងចែកប្រូបាប៊ីលីតេ ដែលអនុគមន៍ដង់ស៊ីតេប្រូបាប៊ីលីតេអាចសរសេរបានក្នុងទម្រង់កាណូនិច៖ \[p(y; \eta) = b(y) \exp\left(\eta^T T(y) - a(\eta)\right)\]
  • ប៉ារ៉ាម៉ែត្រធម្មជាតិ (\(\eta\) - Natural Parameter): ប៉ារ៉ាម៉ែត្រកាណូនិចដែលកំណត់លក្ខណៈនៃបំណែងចែក។
  • ស្ថិតិគ្រប់គ្រាន់ (\(T(y)\) - Sufficient Statistic): អនុគមន៍នៃទិន្នន័យ \(y\) ដែលក្តោបក្តាប់រាល់ព័ត៌មានទាំងអស់អំពីប៉ារ៉ាម៉ែត្រ (ជាទូទៅ \(T(y) = y\))។
  • រង្វាស់មូលដ្ឋាន (\(b(y)\) - Base Measure): កត្តាធ្វើមាត្រដ្ឋានដែលអាស្រ័យតែលើទិន្នន័យ \(y\) ប៉ុណ្ណោះ។
  • អនុគមន៍ Log Partition (\(a(\eta)\)): កត្តាកំណត់ស្តង់ដារដែលធានាថាផលបូក ឬអាំងតេក្រាលនៃប្រូបាប៊ីលីតេមានតម្លៃស្មើ ១ ជានិច្ច៖ \[a(\eta) = \log \int b(y) \exp\left(\eta^T T(y)\right) dy\]
  • អនុគមន៍ភ្ជាប់ (Link Function, \(g^{-1}\)): អនុគមន៍ផ្គូផ្គងតម្លៃរំពឹងទុកនៃបំណែងចែកគោលដៅ ទៅកាន់ប៉ារ៉ាម៉ែត្រធម្មជាតិ \(\eta\)។
  • អនុគមន៍ឆ្លើយតបកាណូនិច (Canonical Response Function, \(g\)): អនុគមន៍ផ្គូផ្គងប៉ារ៉ាម៉ែត្រធម្មជាតិ \(\eta\) ទៅកាន់តម្លៃរំពឹងទុក \(\mathbb{E}[T(y)]\)។
  • អនុគមន៍ Softmax (Softmax Function): ទម្រង់ទូទៅនៃ sigmoid ដែលបម្លែងវ៉ិចទ័រ Logits ទៅជាបំណែងចែកប្រូបាប៊ីលីតេលើ \(k\) ថ្នាក់ដាច់ដោយឡែកពីគ្នា។
  • ការធ្វើឱ្យស្លាកសម្គាល់រលូន (Label Smoothing): បច្ចេកទេស Regularization ដែលជំនួសស្លាកសម្គាល់រឹង One-Hot ដោយបំណែងចែកគោលដៅទន់ និងរលូន ដើម្បីកាត់បន្ថយ Overfitting។

៣. រូបមន្តគណិតវិទ្យា និងការទាញសមីការ

ក. លក្ខណៈសម្បត្តិបង្រួបបង្រួមនៃ \(a(\eta)\)

ដេរីវេនៃអនុគមន៍ Log Partition \(a(\eta)\) ផ្តល់នូវម៉ូម៉ង់ស្ថិតិនៃស្ថិតិគ្រប់គ្រាន់ \(T(y)\) ដោយស្វ័យប្រវត្តិ៖

  1. ដេរីវេទីមួយ (តម្លៃរំពឹងទុក): \[\frac{\partial}{\partial \eta} a(\eta) = \mathbb{E}[T(y)]\]
  2. ដេរីវេទីពីរ (វ៉ារ្យ៉ង់): \[\frac{\partial^2}{\partial \eta^2} a(\eta) = \text{Var}(T(y)) \ge 0\]

ដោយសារវ៉ារ្យ៉ង់មិនអវិជ្ជមានជានិច្ច នោះ \(a(\eta)\) ត្រូវបានធានាថាជា អនុគមន៍ប៉ោង (Convex Function) ធ្វើឱ្យការបង្កើនប្រសិទ្ធភាពតាមជម្រាលមានស្ថេរភាព និងរួមគ្នាមកកាន់ Global Optima ជានិច្ច។

ខ. ភស្តុតាង៖ បំណែងចែក Bernoulli ក្នុង Exponential Family

សម្រាប់ \(p(y; \phi) = \phi^y (1-\phi)^{1-y}\) ដោយសរសេរជា \(\exp(\log(\dots))\) យើងកំណត់បាន៖

  • \(b(y) = 1\)
  • \(T(y) = y\)
  • \(\eta = \log\left(\frac{\phi}{1-\phi}\right) \implies \phi = \frac{1}{1 + e^{-\eta}}\) (Sigmoid Response Function!)
  • \(a(\eta) = \log(1 + e^\eta)\)

គ. ភស្តុតាង៖ បំណែងចែក Gaussian ក្នុង Exponential Family

សម្រាប់ Gaussian ដែលមាន \(\sigma^2 = 1\)៖

\[p(y; \mu) = \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{(y-\mu)^2}{2}\right) = \frac{1}{\sqrt{2\pi}} \exp\left(-\frac{y^2}{2}\right) \exp\left(\mu y - \frac{\mu^2}{2}\right)\]
  • \(b(y) = \frac{1}{\sqrt{2\pi}} \exp(-y^2/2)\)
  • \(T(y) = y\)
  • \(\eta = \mu\)
  • \(a(\eta) = \frac{\mu^2}{2} = \frac{\eta^2}{2}\)

៤. គំរូលីនេអ៊ែរទូទៅ (GLMs)

ការសន្មតរៀបចំចំនួន ៣ នៃ GLM៖

  1. \(y \mid x; \theta \sim \text{ExponentialFamily}(\eta)\)
  2. គោលដៅទស្សន៍ទាយតម្លៃរំពឹងទុក៖ \(h_\theta(x) = \mathbb{E}[T(y) \mid x]\)
  3. ទំនាក់ទំនងលីនេអ៊ែរ៖ \(\eta = \theta^T x\)

ក្រោម MLE គ្រប់បំណែងចែកទាំងអស់ក្នុង Exponential Family សុទ្ធតែចែករំលែកនូវវិធានធ្វើបច្ចុប្បន្នភាពជម្រាលកែកំហុសដូចគ្នាបេះបិទ៖

\[\theta_j := \theta_j - \alpha \left( h_{\theta^{(t)}}(x^{(i)}) - y^{(i)} \right) x_j^{(i)}\]

៥. ការធ្វើចំណាត់ថ្នាក់ពហុថ្នាក់៖ Softmax Regression

សម្រាប់ \(k > 2\) ថ្នាក់ ស្លាកសម្គាល់ត្រូវបានតំណាងដោយវ៉ិចទ័រ One-Hot \(y \in \mathbb{R}^k\) ហើយប៉ារ៉ាម៉ែត្ររួមមាន \(\theta_1, \dots, \theta_k \in \mathbb{R}^{d+1}\)។

រូបមន្ត Softmax

\[p(y = j \mid x; \theta) = \frac{\exp(\theta_j^T x)}{\sum_{l=1}^k \exp(\theta_l^T x)}\]

Cross-Entropy Loss

\[\mathcal{L}(\theta) = -\sum_{i=1}^n \sum_{j=1}^k y_j^{(i)} \log p(y^{(i)} = j \mid x^{(i)}; \theta)\]

៦. ការធ្វើឱ្យស្លាកសម្គាល់រលូន (Label Smoothing)

ជំនួសឱ្យស្លាក One-Hot រឹង \([1, 0, 0, 0]^T\) ដែលរុញទម្ងន់ឱ្យខិតទៅរកអនន្ត Label Smoothing បែងចែកទម្ងន់ប្រូបាប៊ីលីតេតូច \(\epsilon\) ស្មើៗគ្នាទៅគ្រប់ថ្នាក់៖

\[y_{\text{smooth}, j} = y_j (1 - \epsilon) + \frac{\epsilon}{k}\]

ឧទាហរណ៍ សម្រាប់ ៤ ថ្នាក់ជាមួយ \(\epsilon = 0.1\)៖ \([1, 0, 0, 0]^T \implies [0.925, 0.025, 0.025, 0.025]^T\)។ បច្ចេកទេសនេះជួយទប់ស្កាត់ Overfitting, បង្កើនភាពធន់នឹងកំហុសទិន្នន័យ (Label Noise) និងជួយឱ្យលំហូរជម្រាលមានស្ថេរភាពល្អ។

៧. កម្មវិធីអនុវត្តជាក់ស្តែង

  • ការទស្សន៍ទាយ Token បន្ទាប់ក្នុង LLMs: ស្រទាប់ Softmax ដ៏ធំសម្បើមត្រូវបានប្រើជា Prediction Head ចុងក្រោយដើម្បីជ្រើសរើស Token បន្ទាប់ពីវចនានុក្រមទំហំ \(50k - 250k\) Tokens។
  • យន្តការ Self-Attention ក្នុង Transformers: \[\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V\]

៨. សំណួរត្រិះរិះពិចារណា

  1. ភាពប៉ោងតាមបែបគណិតវិទ្យា: ហេតុអ្វីបានជាអនុគមន៍ Log Partition \(a(\eta)\) ត្រូវបានធានាថាជាអនុគមន៍ប៉ោង? (ចម្លើយ៖ ពីព្រោះដេរីវេទីពីរស្មើនឹង \(\text{Var}(T(y)) \ge 0\))។
  2. ភាពច្រំដែលក្នុង Softmax: ចូរបង្ហាញថាការដកវ៉ិចទ័រថេរ \(\psi\) ពីគ្រប់ \(\theta_j\) មិនធ្វើឱ្យប៉ះពាល់ដល់ប្រូបាប៊ីលីតេ Softmax ឡើយ។
  3. ដែនកំណត់នៃភាពខណ្ឌចែកលីនេអ៊ែរ: ហេតុអ្វីបានជាលំហដែលមានវិមាត្រខ្ពស់ (ដូចជា ៧៦៨ វិមាត្ររបស់ GPT-2) ធ្វើឱ្យ Linear Classifiers ដំណើរការបានល្អអស្ចារ្យ?

៩. ឯកសារយោង & ការអានបន្ថែម

  • Convex Optimization (Boyd & Vandenberghe): ជំពូកទី ៣ ស្តីអំពីអនុគមន៍ Log-Convex និង Partition Functions។
