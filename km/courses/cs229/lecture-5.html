មេរៀនទី ៥: ការវិភាគវិនិច្ឆ័យហ្គោស (Gaussian Discriminant Analysis)

Stanford CS229 — មូលដ្ឋានគ្រឹះ និងទម្រង់នៃការរៀនរបស់ម៉ាស៊ីន

១. សេចក្តីសង្ខេបនៃគំនិតចម្បងៗ

មេរៀននេះណែនាំអំពីគោលគំនិតនៃ ក្បួនដោះស្រាយការរៀនបែបបង្កើត / ពូជ (Generative Learning Algorithms) ដែលជាការផ្លាស់ប្តូរបទដ្ឋានគំនិត (Paradigm Shift) ដ៏សំខាន់ខុសប្លែកពីក្បួនចាត់ថ្នាក់បែបវិនិច្ឆ័យ (Discriminative Classifiers)។ ខណៈដែលក្បួនដោះស្រាយបែបវិនិច្ឆ័យ ដូចជា Linear Regression និង Logistic Regression ធ្វើការប៉ាន់ស្មានដោយផ្ទាល់ទៅលើប្រូបាប៊ីលីតេក្រោយ \(P(y|x)\) ក្បួនដោះស្រាយបែបបង្កើតផ្តោតលើការកសាងម៉ូដែលប្រូបាប៊ីលីតេរួម \(P(x, y)\) តាមរយៈការរៀនបំណែងចែកលក្ខណៈទិន្នន័យតាមលក្ខខណ្ឌថ្នាក់ \(P(x|y)\) និងប្រូបាប៊ីលីតេមុន \(P(y)\)។

សាស្ត្រាចារ្យ Chris Ré បានលើកយក ការវិភាគវិនិច្ឆ័យហ្គោស (Gaussian Discriminant Analysis - GDA) សម្រាប់ទិន្នន័យបន្តបន្ទាប់ និង ក្បួនចាត់ថ្នាក់ណៃវបាយេស (Naive Bayes Classifier) សម្រាប់ទិន្នន័យអត្ថបទដាច់ៗពីគ្នា។ ចំណុចខ្លាំងដ៏ពិសេសនៃម៉ូដែលបែបបង្កើតគឺ សមត្ថភាពក្នុងការគណនាប៉ារ៉ាម៉ែត្រក្នុងទម្រង់បិទជិត (Closed-form Joint MLE) ដោយពុំចាំបាច់ធ្វើការបង្ශើលជម្រាលដដែលៗ (Gradient Descent) ឡើយ។ មេរៀនបញ្ចប់ដោយការបង្ហាញពីទំនាក់ទំនងទ្រឹស្តីរវាង GDA និង Logistic Regression ព្រមទាំងការផ្សារភ្ជាប់ទៅកាន់បច្ចេកវិទ្យា Generative AI ទំនើបៗដូចជា Diffusion Models និង LLMs។

២. គោលគំនិតសំខាន់ៗ & និយមន័យ

  • ក្បួនដោះស្រាយបែបវិនិច្ឆ័យ (Discriminative Algorithms): ក្បួនចាត់ថ្នាក់ដែលរៀនស្វែងរកព្រំដែនសម្រេចចិត្តដោយផ្ទាល់ ដើម្បីប៉ាន់ស្មាន \(P(y|x)\)។
  • ក្បួនដោះស្រាយបែបបង្កើត (Generative Algorithms): ក្បួនចាត់ថ្នាក់ដែលកសាងម៉ូដែល \(P(x|y)\) និង \(P(y)\) រួចប្រើប្រាស់វិធានបាយេស (Bayes' Rule) ដើម្បីទស្សន៍ទាយ \(P(y|x) = \frac{P(x|y)P(y)}{P(x)}\)។
  • បំណែងចែកហ្គោសពហុវិមាត្រ (Multivariate Gaussian Distribution): បំណែងចែកប្រក្រតីសម្រាប់វ៉ិចទ័រ \(x \in \mathbb{R}^d\) ដែលកំណត់ដោយវ៉ិចទ័រមធ្យម \(\mu \in \mathbb{R}^d\) និងម៉ាទ្រីសកូវ៉ារ្យ៉ង់ស៊ីមេទ្រី កំណត់វិជ្ជមាន \(\Sigma \in \mathbb{R}^{d \times d}\)។
  • ម៉ាទ្រីសកូវ៉ារ្យ៉ង់ (\(\Sigma\) - Covariance Matrix): ម៉ាទ្រីសដែលកំណត់ទំហំ ទម្រង់ពងក្រពើ និងទិសដៅនៃខ្សែវណ្ឌប្រូបាប៊ីលីតេ។
  • ម៉ាទ្រីសភាពជាក់លាក់ (\(\Sigma^{-1}\) - Precision Matrix): ច្រាសនៃម៉ាទ្រីសកូវ៉ារ្យ៉ង់ ដែលតម្លៃសូន្យ (\(\Sigma^{-1}_{ij} = 0\)) បញ្ជាក់ពីភាពឯករាជ្យតាមលក្ខខណ្ឌរវាងលក្ខណៈទិន្នន័យទី \(i\) និង \(j\)។
  • ការវិភាគវិនិច្ឆ័យហ្គោស (GDA): ម៉ូដែលបែបបង្កើតសម្រាប់ទិន្នន័យបន្តបន្ទាប់ ដែលសន្មតថា \(P(x|y)\) ជាបំណែងចែកហ្គោសពហុវិមាត្រដោយចែករំលែកម៉ាទ្រីសកូវ៉ារ្យ៉ង់រួម \(\Sigma\) តែមួយ ប៉ុន្តែមានមធ្យមរៀងៗខ្លួន \(\mu_0, \mu_1\)។
  • ការវិភាគវិនិច្ឆ័យការ៉េ (QDA): ទម្រង់ទូទៅនៃ GDA ដែលអនុញ្ញាតឱ្យថ្នាក់នីមួយៗមានម៉ាទ្រីសកូវ៉ារ្យ៉ង់ផ្ទាល់ខ្លួន (\(\Sigma_0 \neq \Sigma_1\)) បង្កើតបានជាព្រំដែនសម្រេចចិត្តរាងខ្សែកោងការ៉េ។
  • ក្បួនចាត់ថ្នាក់ណៃវបាយេស (Naive Bayes): ម៉ូដែលបែបបង្កើតសម្រាប់ទិន្នន័យដាច់ៗពីគ្នា ដែលសន្មតថាលក្ខណៈទិន្នន័យនីមួយៗឯករាជ្យតាមលក្ខខណ្ឌពីគ្នាទៅវិញទៅមក នៅពេលដឹងស្លាកថ្នាក់ \(y\)។
  • ការធ្វើឱ្យរលូនបែបឡាផ្លាស (Laplace Smoothing): បច្ចេកទេសបន្ថែមចំនួនរាប់សិប្បនិម្មិត \(+1\) ដើម្បីការពារកុំឱ្យកើតមានប្រូបាប៊ីលីតេសូន្យចំពោះពាក្យដែលមិនធ្លាប់ជួបក្នុងទិន្នន័យបង្វឹក។

៣. រូបមន្តគណិតវិទ្យា & ការប៉ាន់ស្មានប៉ារ៉ាម៉ែត្រ GDA

អនុគមន៍ដង់ស៊ីតេប្រូបាប៊ីលីតេហ្គោសពហុវិមាត្រ៖

\[p(x; \mu, \Sigma) = \frac{1}{(2\pi)^{d/2} |\Sigma|^{1/2}} \exp \left( -\frac{1}{2} (x - \mu)^T \Sigma^{-1} (x - \mu) \right)\]

ការប៉ាន់ស្មានប៉ារ៉ាម៉ែត្រទម្រង់បិទជិត (Closed-Form Joint MLE)៖

  • \(\phi = \frac{1}{n} \sum_{i=1}^n \mathbb{I}(y^{(i)} = 1)\)
  • \(\mu_0 = \frac{\sum_{i=1}^n \mathbb{I}(y^{(i)} = 0) x^{(i)}}{\sum_{i=1}^n \mathbb{I}(y^{(i)} = 0)}\)
  • \(\mu_1 = \frac{\sum_{i=1}^n \mathbb{I}(y^{(i)} = 1) x^{(i)}}{\sum_{i=1}^n \mathbb{I}(y^{(i)} = 1)}\)
  • \(\Sigma = \frac{1}{n} \sum_{i=1}^n (x^{(i)} - \mu_{y^{(i)}}) (x^{(i)} - \mu_{y^{(i)}})^T\)

៤. ព្រំដែនសម្រេចចិត្តលីនេអ៊ែរ និងក្រាហ្វិកអន្តរកម្ម

ដោយសារតែម៉ាទ្រីសកូវ៉ារ្យ៉ង់ \(\Sigma\) ត្រូវបានចែករំលែករួមគ្នារវាងថ្នាក់ទាំងពីរ តួការ៉េ \(x^T \Sigma^{-1} x\) ត្រូវបានសម្រួលកាត់ចោលអស់ នាំឱ្យព្រំដែនសម្រេចចិត្តមានទម្រង់លីនេអ៊ែរអាហ្វីន៖

\[\theta^T x + \theta_0 = 0\]

ដែល \(\theta = \Sigma^{-1} (\mu_1 - \mu_0)\) និង \(\theta_0 = -\frac{1}{2} \mu_1^T \Sigma^{-1} \mu_1 + \frac{1}{2} \mu_0^T \Sigma^{-1} \mu_0 + \ln \frac{\phi}{1-\phi}\)។

រូបភាព៖ ការប្រៀបធៀបព្រំដែនសម្រេចចិត្តរវាង GDA (បន្ទាត់ត្រង់លីនេអ៊ែរ) និង QDA (ខ្សែកោងការ៉េ) លើបំណែងចែកហ្គោស។

៥. ការប្រៀបធៀបរវាង GDA និង Logistic Regression

លក្ខណៈវិនិច្ឆ័យ ការវិភាគវិនិច្ឆ័យហ្គោស (GDA) ការវិភាគតម្រែតម្រង់ឡូជីស្ទីក (Logistic Regression)
ទម្រង់ម៉ូដែល បែបបង្កើត (Generative: \(P(x, y)\)) បែបវិនិច្ឆ័យ (Discriminative: \(P(y|x)\))
កម្រិតសន្មត ខ្លាំង (សន្មតថាទិន្នន័យជា Multivariate Gaussian) ខ្សោយ (សន្មតត្រឹមតែថា Log-odds មានទម្រង់លីនេអ៊ែរ)
ប្រសិទ្ធភាពទិន្នន័យ ខ្ពស់ (ត្រូវការទិន្នន័យតិចបើការសន្មតត្រឹមត្រូវ) ទាបជាង (ត្រូវការទិន្នន័យច្រើនដើម្បីរៀនប៉ារ៉ាម៉ែត្រ)
ភាពធន់នឹងគម្លាតទិន្នន័យ ងាយរងគ្រោះ (ធ្លាក់ចុះគុណភាពខ្លាំងបើមិនមែន Gaussian) រឹងមាំខ្លាំង (ធន់នឹងទិន្នន័យលម្អៀង ឬខុសប្លែក)
វិធីសាស្ត្រគណនា រូបមន្តបិទជិត (គណនាភ្លាមៗ គ្មាន Iteration) វិធីសាស្ត្របង្ශើលជម្រាលដដែលៗ (SGD)
