Stanford CS229 — មូលដ្ឋានគ្រឹះ និងទម្រង់នៃការរៀនរបស់ម៉ាស៊ីន

ទំព័រដើម / វគ្គសិក្សា / CS229 / មេរៀនទី ៨

១. សេចក្តីសង្ខេបនៃគំនិតចម្បងៗ

មេរៀននេះរៀបរាប់យ៉ាងលម្អិតអំពី ការផ្សាយបញ្ច្រាស (Backpropagation) ឬ Reverse-mode Automatic Differentiation ដែលជាក្បួនដោះស្រាយស្នូលក្នុងការគណនាជម្រាលនៃអនុគមន៍កំហុសធៀបនឹងគ្រប់ប៉ារ៉ាម៉ែត្រទាំងអស់នៃបណ្តាញញាណ។ តាមរយៈទ្រឹស្តីបទនៃ សៀគ្វីដេរីវេបាន (Differentiable Circuits) ប្រសិនបើការផ្សាយទៅមុខចំណាយពេល \(O(N)\) នោះជម្រាលទាំងអស់អាចត្រូវបានគណនាក្នុងរយៈពេលដូចគ្នាបេះបិទគឺ \(O(N)\) ក្នុងដំណើរការផ្សាយបញ្ច្រាស។

សាស្ត្រាចារ្យ Tengyu បានបកស្រាយលម្អិតពីការទាញរកដេរីវេវ៉ិចទ័រ និងម៉ាទ្រីសតាមរយៈ វិធានច្រវាក់ពហុអថេរ (Multivariate Chain Rule) សម្រាប់ស្រទាប់គុណម៉ាទ្រីស (\(u = Wz + b\)) ដោយបង្ហាញពីទំនាក់ទំនងទៅនឹង ការរៀនបែបហេបប៊ី (Hebbian Learning) ក្នុងប្រព័ន្ធប្រសាទជីវសាស្ត្រ (\(\frac{\partial J}{\partial W} = \gamma z^T\)) និងស្រទាប់អនុគមន៍សកម្មកម្ម (\(u = \sigma(z)\)) ជាមួយផលគុណ Hadamard \(\odot\)។ មេរៀនបញ្ចប់ដោយការស្វែងយល់ពី ផលគុណ Hessian-Vector និងវិស្វកម្មអង្គចងចាំ Activation Caching លើ GPU។

២. គោលគំនិតសំខាន់ៗ & និយមន័យ

  • សៀគ្វីដេរីវេបាន (Differentiable Circuit): ក្រាហ្វគណនា DAG នៃប្រតិបត្តិការបឋម និងអនុគមន៍ដេរីវេបាន។
  • ការផ្សាយបញ្ច្រាស (Backpropagation): ក្បួនដោះស្រាយដែលអនុវត្តវិធានច្រវាក់ពីទិន្នផលត្រឡប់មកធាតុចូលវិញ។
  • ម៉ាទ្រីសហ្សាខូប៊ី (Jacobian Matrix): ម៉ាទ្រីសនៃដេរីវេដោយផ្នែកលំដាប់ទីមួយទាំងអស់នៃអនុគមន៍វ៉ិចទ័រធៀបនឹងធាតុចូលរបស់វា។
  • ផលគុណហាដាម៉ាដ (Hadamard Product, \(\odot\)): ផលគុណគុណតាមធាតុនីមួយៗនៃវ៉ិចទ័រ ឬម៉ាទ្រីសពីរ។
  • វិធានរៀនបែបហេបប៊ី (Hebbian Learning Rule): គោលការណ៍ជីវសាស្ត្រដែលទម្ងន់ស៊ីណាប់ជាផលគុណនៃសញ្ញាមុន និងក្រោយស៊ីណាប់ (\(\frac{\partial J}{\partial W_{ij}} = \frac{\partial J}{\partial u_i} z_j\))។
  • ផលគុណហេសស៊ាន-វ៉ិចទ័រ (Hessian-Vector Product): ការគណនា \(Hv\) ក្នុងរយៈពេល \(O(N)\) ដោយពុំចាំបាច់បង្កើតម៉ាទ្រីស Hessian \(N \times N\) ពេញលេញ។
  • Activation Caching: ការរក្សាទុកតម្លៃ Activations កម្រិតមធ្យមក្នុង GPU HBM សម្រាប់ប្រើប្រាស់កំឡុងពេល Backward Pass។

៣. រូបមន្តគណិតវិទ្យា & វិធានច្រវាក់វ៉ិចទ័រ

វិធានច្រវាក់ពហុអថេរជាទម្រង់ម៉ាទ្រីសហ្សាខូប៊ី៖

\[\frac{\partial J}{\partial z} = \left(\frac{\partial g}{\partial z}\right)^T \frac{\partial J}{\partial u}\]

ស្រទាប់គុណម៉ាទ្រីស (\(u = Wz + b\))៖

  • ជម្រាលធៀបនឹងធាតុចូល \(z\)៖ \(\frac{\partial J}{\partial z} = W^T \frac{\partial J}{\partial u}\)
  • ជម្រាលធៀបនឹងទម្ងន់ \(W\) (Outer Product, Rank-1)៖ \(\frac{\partial J}{\partial W} = \left(\frac{\partial J}{\partial u}\right) z^T\)
  • ជម្រាលធៀបនឹងលម្អៀង \(b\)៖ \(\frac{\partial J}{\partial b} = \frac{\partial J}{\partial u}\)

ស្រទាប់អនុគមន៍សកម្មកម្ម (\(u = \sigma(z)\))៖

\[\frac{\partial J}{\partial z} = \sigma'(z) \odot \frac{\partial J}{\partial u}\]

៤. លំហូរការងារការផ្សាយបញ្ច្រាស & ក្រាហ្វិកអន្តរកម្ម

ដំណើរការ ៤ ជំហាននៃការផ្សាយបញ្ច្រាសតាមស្រទាប់នីមួយៗ៖

  1. \(\gamma^{(l)} = \delta^{(l)} \odot \sigma'\left(z^{(l)}\right)\)
  2. \(\frac{\partial J}{\partial W^{(l)}} = \gamma^{(l)} \left(a^{(l-1)}\right)^T\)
  3. \(\frac{\partial J}{\partial b^{(l)}} = \gamma^{(l)}\)
  4. \(\delta^{(l-1)} = \left(W^{(l)}\right)^T \gamma^{(l)}\)

រូបភាព៖ ក្រាហ្វគណនានៃការផ្សាយបញ្ច្រាស — ដំណើរការ Forward Pass (ឆ្វេងទៅស្តាំ) និង Backward Pass (ស្តាំទៅឆ្វេង)។

៥. ផលគុណ Hessian-Vector ក្នុងរយៈពេល \(O(N)\)

ដើម្បីគណនាផលគុណហេសស៊ាន-វ៉ិចទ័រ \(H(\theta) v\) ដោយពុំចាំបាច់ចំណាយអង្គចងចាំ \(O(N^2)\) យើងកំណត់អនុគមន៍ស្កាលែជំនួយ៖

\[g(\theta) = \left(\nabla_\theta J(\theta)\right)^T v\]

បន្ទាប់មកធ្វើដេរីវេលើកទីពីរតាមរយៈការផ្សាយបញ្ច្រាស៖

\[\nabla_\theta g(\theta) = \nabla_\theta \left( \nabla_\theta J(\theta)^T v \right) = H(\theta) v\]

ដំណើរការនេះចំណាយពេល និងអង្គចងចាំត្រឹមតែ \(O(N)\) ប៉ុណ្ណោះ។
