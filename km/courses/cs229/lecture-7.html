១. សេចក្តីសង្ខេបនៃគំនិតចម្បងៗ

មេរៀននេះណែនាំអំពីស្ថាបត្យកម្មគ្រឹះនៃ Deep Learning និង បណ្តាញញាណសិប្បនិម្មិត (Neural Networks) ដោយផ្លាស់ប្តូរទស្សនវិស័យពីម៉ូដែលលីនេអ៊ែរ ទៅកាន់ម៉ូដែលមិនលីនេអ៊ែរដែលមានប៉ារ៉ាម៉ែត្រ (Parameterized Nonlinear Models)។ មេរៀនបានគ្របដណ្តប់លើបញ្ហា Continuous Regression និង Multi-Class Classification ដោយប្រើប្រាស់អនុគមន៍ Softmax និងកំហុស Cross-Entropy Loss។

សាស្ត្រាចារ្យបានពន្យល់ពីមូលហេតុដែលវិធីសាស្ត្រលំដាប់ទីពីរ (ដូចជា Newton's Method) ទទួលបរាជ័យក្នុងស្ថានភាពមិនប៉ោង (Non-convexity) ដោយសារចំណុចកែបសេះ (Saddle points) និងបានបង្ហាញពីសារៈសំខាន់នៃ Minibatch Stochastic Gradient Descent (SGD) ក្នុងនាមជាអ្នកប៉ាន់ស្មានមិនលម្អៀង (Unbiased estimator) ដែលទាញយកអត្ថប្រយោជន៍ពេញលេញពី GPU Hardware។ ជាចុងក្រោយ មេរៀនបានកសាងបណ្តាញញាណពីណឺរ៉ុនទោល អនុគមន៍សកម្មកម្ម (ReLU, Sigmoid, GELU), Multi-layer Perceptron (MLP), Residual Connections (ResNets) និង Layer Normalization (LayerNorm, RMS Norm)។

២. គោលគំនិតសំខាន់ៗ & និយមន័យ

  • ម៉ូដែលមិនលីនេអ៊ែរ (Nonlinear Model): ម៉ូដែលដែលមិនលីនេអ៊ែរធៀបនឹងប៉ារ៉ាម៉ែត្ររបស់វា (\(\theta\))។
  • ឡូជីត (Logits): តម្លៃទិន្នផលវិមាត្រ \(k\) មិនទាន់ធ្វើស្តង់ដារមុនពេលបញ្ជូនកាត់ Softmax។
  • អនុគមន៍សកម្មកម្ម (Activation Function, \(\sigma\)): អនុគមន៍មិនលីនេអ៊ែរដែលផ្តល់សមត្ថភាពបញ្ចេញមតិដល់បណ្តាញញាណ។
  • Multi-layer Perceptron (MLP): បណ្តាញញាណផ្សាយទៅមុខដែលមានស្រទាប់គុណម៉ាទ្រីសជង់លើគ្នា អមដោយអនុគមន៍សកម្មកម្មមិនលីនេអ៊ែរ។
  • ប្លុកសំណល់ (Residual Block): សមាសភាគដែលបូកបញ្ចូលធាតុចូលដោយផ្ទាល់ត្រឡប់ទៅកាន់ទិន្នផល (\(\text{Res}(z) = F(z) + z\)) ដើម្បីដោះស្រាយបញ្ហាជម្រាលរលាយបាត់ (Vanishing Gradients)។
  • ភាពមិនប្រែប្រួលតាមមាត្រដ្ឋាន (Scaling Invariance): លក្ខណៈសម្បត្តិនៃ LayerNorm/RMSNorm ដែល \(\text{LN}(\alpha z) = \text{LN}(z)\) សម្រាប់ \(\alpha > 0\)។
  • ខនវ៉ូលូសិន (Convolution): ប្រតិបត្តិការគុណម៉ាទ្រីសដែលមានរចនាសម្ព័ន្ធចែករំលែកទម្ងន់ និងកំណត់ត្រឹមដែនទទួលសញ្ញាក្នុងតំបន់ (Local Receptive Fields)។

៣. រូបមន្តគណិតវិទ្យា & Cross-Entropy Loss

អនុគមន៍ Softmax៖

\[P(y = j \mid x; \theta) = \frac{e^{h_{\theta, j}(x)}}{\sum_{l=1}^k e^{h_{\theta, l}(x)}}\]

រូបមន្ត Cross-Entropy Loss (ទាញចេញពី Negative Log-Likelihood)៖

\[\mathcal{L}_{\text{CE}}(\theta) = -\log P(y \mid x; \theta) = -h_{\theta, y}(x) + \log \sum_{l=1}^k e^{h_{\theta, l}(x)}\]

៤. Minibatch SGD & ក្រាហ្វិកអន្តរកម្ម

ការធ្វើបច្ចុប្បន្នភាព Minibatch SGD លើកញ្ចប់ \(\mathcal{B}\) ទំហំ \(B\)៖

\[\theta := \theta - \eta \left( \frac{1}{B} \sum_{i \in \mathcal{B}} \nabla_\theta \mathcal{L}_i(\theta) \right)\]

Minibatch SGD គឺជាអ្នកប៉ាន់ស្មានមិនលម្អៀងនៃជម្រាលពេញលេញ៖ \(\mathbb{E}[\nabla_\theta \mathcal{L}_{\mathcal{B}}(\theta)] = \nabla_\theta \mathcal{L}(\theta)\)។

រូបភាព៖ ការប៉ាន់ស្មានជម្រាលដោយ Minibatch SGD — ចំណុចកណ្តាលនៃជម្រាលស្តូកាស្ទីក (ព្រួញខៀវ) តម្រង់ជួរស្មើនឹងជម្រាលពេញលេញ (ព្រួញខ្មៅ)។

៥. Residual Connections & Layer Normalization

រូបមន្តប្លុកសំណល់ ResNet៖

\[\text{Res}(z) = F(z) + z = \sigma\left(W^{(2)} \sigma\left(W^{(1)} z + b^{(1)}\right) + b^{(2)}\right) + z\]

រូបភាព៖ ស្ថាបត្យកម្មប្លុកសំណល់ (Residual Block) ជាមួយផ្លូវកាត់ Skip Connection។

RMS Norm (Root Mean Square Normalization)៖

\[\hat{\sigma} = \sqrt{\frac{1}{m} \sum_{i=1}^m z_i^2}, \quad \text{RMSNorm}(z) = \gamma \odot \left( \frac{z}{\hat{\sigma} + \epsilon} \right)\]
