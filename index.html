Welcome

This is a static portfolio of lecture notes and study materials for Stanford CS229, the foundational machine learning course taught in Spring 2026. The site is inspired by the academicpages.github.io template and is built as a purely static site (HTML, CSS, JavaScript).

Notes are organized by lecture and cover topics from supervised learning, unsupervised learning, reinforcement learning, and modern deep learning paradigms.
